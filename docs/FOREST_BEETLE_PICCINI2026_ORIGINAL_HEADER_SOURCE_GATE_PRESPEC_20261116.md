# Piccini 2026 full three-stratum beetles: original official Dataverse first-line HEADER ONLY gate (2026-11-16)

## Motivation and dependency

The prior [metadata-only prespec](FOREST_BEETLE_PICCINI2026_THREESTRATA_SOURCE_ONLY_PRESPEC_20261116.md) freezes study/source identity, independence and avoidance of the original species outcomes. Official public DataCite and GRO.data API both returned HTTP200 for [DOI 10.25625/H8EMJS](https://doi.org/10.25625/H8EMJS) and older [10.25625/5AWJBC](https://doi.org/10.25625/5AWJBC) in [original source-only Actions #43874968214](https://github.com/zuizui0223/Structural/actions/runs/43874968214). Two published un-restricted text-type file metadata entries were reported for each DOI; the 2026 set totals 2,245,670 advertised bytes and 2024 set 325,412. An overly strict source-ID parser did not recognize the Dataverse's native DOI component fields, giving source identity STOP despite successful original HTTP/metadata. Source-only code has been amended to validate native `protocol+authority+identifier` or exact `datasetPersistentId`. Never treat its first STOP as ecological null.

**This is a NEW, separately frozen, prebiological source field-header gate.** No earlier source metadata gate is redefined; all 2024/2026 source biological values are still unopened. Full publication Piccini et al. (2026), DOI 10.1111/1365-2664.70472, already analysed stand identity × layer and feeding guilds. Thus the published finding is prior art, not a new discovery.

## Exact method

1. Use only the 2026 full-layer source DOI `10.25625/H8EMJS`; the older 2024 canopy DOI is documented as overlapping prior source **and receives NO file-content request**. Request original DataCite and GRO Dataverse public metadata ONCE each, using the published `GET /api/datasets/:persistentId/?persistentId=doi:10.25625/H8EMJS` endpoint.
2. Proceed only if DataCite DOI, title, publisher and year match a public record, AND native GRO source DOI identity exactly matches, source version `RELEASED`, and **exactly two** current original metadata file entries are visible. Reject any `restricted=true`, missing nonnumeric dataFile id, zero/oversize `filesize`, unsupported MIME or absent original identifiers.
3. For each of those exactly two files (no filename-based ecological outcome selection), issue at most **one** official public `GET /api/access/datafile/<original-dataFile-id>` using standard `Range: bytes=0-8191`. Parse **ONLY the first line up to 8192 bytes**, then close the network stream immediately. If unavailable / HTTP401/403 / 404 / range error / no newline, retain explicit SOURCE STOP without retry, URL variants or downloading alternate mirrors. Do not parse, print, process or copy the remainder, any actual occurrence/count/species/trait/environment/site-data rows or file contents. This header read is **not** a biological-source response score.
4. The only allowed record is sanitized **column count**, delimiter category and presence/absence of exact generic whitelist header *categories* among `site/stand/plot, stratum/layer, year, method/effort, species/taxon, guild/host-tree, tree/forest`. Original field spelling, species taxon, location, source file name, site ID, amount and any header cell outside whitelist are not exported. Treat no generic field as an inconclusive header, not a biological null. Some original 2026 columns may be species-name headers; never export their text.
5. The output status is **candidate field-grain evidence** even if headers contain all categories, because shared physical plot/stand/year identities and trap-effort comparability require a subsequent method crosswalk. No merging of canopy/floor observations, no 8-site×5-stand×3-layer pseudoreplication, no trait-based cross-country meta analysis, no model fitting or p-values.
6. Previous original Thai / Finland / PREDICTS / NEON / BALA and GEB scoring protections remain intact. No eBird or TinyFish. PR #469 remains Draft.

## Uncertainty and progress rule

This source-only header gate makes one legitimate attempt. A restricted dataset is a terminal access blocker. A source with metadata-only access but no first-line access does **not** license a fabricated forest-guild effect. The next empirical step is a separately specified **original author-identified site×stand×stratum×sampling-year and trap method check**. The previously published study already has field results; only a precommitted out-of-site prediction beyond author prior art would count as a distinct Structural test.
