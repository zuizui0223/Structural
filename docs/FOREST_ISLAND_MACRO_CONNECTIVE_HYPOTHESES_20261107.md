# 森林マクロ生態学 × 島嶼生態学：接続仮説と実測支持範囲（2026-11-07）

## 主線：同じ生息地面積でも、なぜ森林群集が異なるのか

**問い**：気候・土壌・森林量が似ているのに森林群集の残存／置換が異なるのは、現地林冠構造（植生による環境フィルタ）と、対象種にとって実際に利用可能な森林供給源の配置（種特異的な到達機会）という二条件がずれるためか。

「森林断片＝海洋島」ではない。異なる隔離起源を同じ説明変数とみなさず、同じ**予測階層の追加価値**が条件付きで成立するかを問う。森林断片では、耕地・二次林・都市化域など**マトリクスの通過可能性**を分散様式に応じてモデル化する必要がある。海洋では海上移動の過程を別に定義する。

## 既存の島嶼生態学で確認された知見（移転するのは「事実」ではなく「予測」）

- Structural / GEB v1.180：全球5,401島、529種の事前固定1–4パイロット存在層。2,182,654ホールドアウト島×種セル。実在presenceのC−R3 log loss **−0.5963**（block bootstrap 95% CI −0.7439〜−0.4645）、実際の隣接関係が20/20の次数・辺長一致帰無を上回る。**非常に疎な出現状態では、供給源の数と距離のみでは捕まえられない配置情報が存在予測に残る**という経験的結果。
- 96種・5–12存在層では、全体改善は事前の支持条件を満たさず、実グラフの固有効果も確認されなかった。一方、presence予測の方向は改善側に逆転。79種の高占有探索層は主にabsenceの予測改善であり、実グラフは帰無より優位でなかった。**稀少であれば必ず配置が効く、という一般則は未支持**。
- 独立BALA三時点ソース喪失試験（20種・64行）で将来の局所消失予測へのsource leverage追加は**不支持**（C−R2=+0.000674、95% CI −0.02130〜+0.02558）。したがって森林でも、現在存在の追加予測を再定着／人口動態の因果証拠として扱わない。
- アゾレスBALA/SLAM森林環境パイロットは、標高に沿った非固有在来種数の負の関連（200mあたり地表−1.347、枝叩き−3.712、SLAM−1.940）、地表対樹上植生の起源構成傾斜差（−2.599、q=0.001875）、既知島内森林ブロック除外予測での標高追加による誤差減少（34.0%/59.2%/30.2%）を支持。*島内の環境フィルタの実在*を示す一方、全球の供給源ネットワーク効果を証明しない。

出典：`manuscript/submission/GEB_v1_180/blinded_main_text.md` と `docs/FOREST_MACRO_RESPONSE_AND_MATCHED_METHODS_20261106.md`。元GEBのScientific HOLD、BALA原スコアの凍結を変更しない。

## 新しい統合予測（森林群集については全て未検証）

1. **局所フィルタ**：同じ気候・森林量でも、相対的に異なる林冠構造をもつ森林の群集組成・森林専門種の成立確率は異なる。絶対樹冠高と、気候・土壌・同一森林帯の低攪乱参照分布からの**条件付き構造偏差**を別候補として比較する。参照は応答を読む前に定義。
2. **到達機会**：同じ局所環境であっても、比較対象の種が占有する供給源森林の空間配置は、環境＋森林量＋最短Euclidean供給源距離を越える追加予測情報を持つ場合がある。
3. **占有状態による切替**：供給源配置の追加予測力は、地域の占有率／供給源数と相互作用する。島の1–4/5–12/≥13という絶対種数閾値を森林に転記せず、事前に森林ネットワークの観測支持・調査機会に合わせた階層を設定する。主なendpointは*存在*、不在は別に評価。
4. **通過可能性**：森林外のマトリクスの種類と生物の分散様式によって、単純距離・森林だけの経路・抵抗面経路の相対性能が変わる。海洋島と森林断片に共通するのは「供給源の構成が問題となり得る」という問いであり、**抵抗値や到達距離を共有することではない**。
5. **群集の独自性**：森林専門群（別の種特性原本から独立に定義）・局所固有性を、全世界共通の種数だけでなく「同一原調査系／同一生物地理プール内で、どの種が保たれるか」で検定する。各地域で種名が違うだけで「森林劣化」と判定しない。

## 検定の固定階層

各生物endpointに対し、**まず同一のholdout単位・ベースモデル**を使う。

| 段階 | 説明変数 | 何が追加で説明されるか |
|---|---|---|
| E0 | 気候・土壌・地形・原区画面積・調査方法／努力 | 環境の基本状態 |
| E1 | 森林量・パッチ面積・森林連続性／林縁 | 一般的な森林景観 |
| E2 | 現地樹高・林冠構造、環境条件付き構造偏差 | 局所生息地フィルタ |
| E3 | *学習専用*の占有供給源数、最短Euclidean距離、拡散的供給源圧 | 種に利用可能な資源供給源（直接距離） |
| C | 宣言した分散operatorに対応する森林経路、実接続と一致度、E2×供給源の相互作用 | 供給源経路と局所環境の非冗長性 |

E3/Cを**一つの任意スカラー「連結性」**にまとめない。森林内移動・樹冠間移動・花粉移動・種子分散では抵抗面とendpointが違う。構造データが未取得ならE2をすでに実行したと記録しない。空間グラフの作成は生物応答を見る前に固定し、事後的に有意な移動スケールを選ばない。

生物学的評価は**leave-study/region-out**、可能なら**leave-biome-out**。種特異的供給源を作るときには、予測対象の地域とその完全なholdout blockの応答を供給源情報から除外し、学習側のみで形成する。サンプル外の未観測森林を「未占有」とみなさない。元観測密度・現地努力が十分な原調査系でなければ、E3/C自体を不適格とする。

**帰無比較**：距離・次数・森林面積・検出条件が対応する事前固定の無作為化ネットワーク（20本以上を固定）。森林マトリクスの違いに基づく経路だけが実在グラフの追加価値を残す場合に、観測される森林ネットワークへの特異性が支持される。

## 実際に確認した全球森林観測の支持範囲

### NHM PREDICTS（地点要約原本）

森林Biomes・原Habitat・土地利用の厳格3条件で4,920地点、315研究、64か国、7森林バイオーム。2参照／2改変を同一研究×方法×分類群で比較できる39群・1,145地点は2森林バイオームに限定。採集2019年以降の厳格森林地点0。**2020年の10m樹高をこれらの歴史調査と同時点扱いしない。**

### sPlotOpen v76（公開のNetzschleuder変換データ：2026-11-07実監査）

GitHub Actions #42371685333 / #42371864174 のCIが成功。137,633 nodesのうち95,104は異なる原植生区画。現地の**調査者分類Forest=TRUE**の区画が**33,170（93か国、84原データセット、10気候バイオームラベル）**。調査者の森林分類とは別に種の成長形から作られた`is_forest=TRUE`が38,282あるが、後者を分析対象選択に使わない（生物応答由来のselection bias）。

森林区画の現地樹高6,282、樹木層被度8,022、両方4,887、環境PCsは全33,170。**ただし採集対象が「全維管束植物」の8,645森林区画中、樹高はわずか8・樹木層被度10**。ほぼ全ての構造サブセットは「採集植物の範囲Not specified」に偏り、構造のある区画を無条件に完全群集とみなすことはできない。調査方法別に原GIVDソースの手順を取得するまで、全球群集組成×林冠構造の主要効果は**未実行**とする。

現地樹高／被度は当時の原調査値で、2020年衛星樹高とは異なる。sPlotOpenは環境バランス抽出であり地理的代表性を保証しない。またGIVD 1データセットに多くの区画が含まれることは**独立した森林地域が多い**ことを保証しない。

### 7件の近年GBIF原Eventネットワーク

4件の原Eventコア計910行を原アーカイブで検証（タイ甲虫288、タイ膜翅目288、米国ハチ28、ノルウェー森林植生306）。タイの両分類群で全36座標ペア一致し、独立する2森林研究とは数えない。詳細は`docs/FOREST_MACRO_ORIGINAL_EVENT_GRAIN_AUDIT_20261107.md`。

## 実装・追加の取得ゲート

主線は**森林群集の多地域反復を増やし、島嶼で支持された「供給源の配置が稀な種の存在を予測する」を森林構造との相互作用として検定すること**。

次段階：元GIVDデータセットの調査法を含むsPlotOpenの森林サブセットで、**採集対象／区画面積／調査年／環境変数の揃った群集原本**を構築する。現地での植物群集の種組成と森林構造を同時に扱える採集層が十分か、データ元ごとに判定。足りないなら2020年代の森林植生調査や別の森林モニタリングから独立地域を追加する。未適格な1,000区画を増やしても「全球実証」とは呼ばない。

単回観測は現在の群集組成・存在の予測まで。**source-loss→将来の消失**は三時点等の反復調査系を得るまで保留。
