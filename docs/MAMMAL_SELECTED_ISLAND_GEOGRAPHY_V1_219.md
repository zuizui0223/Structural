# Mammal-conditioned island selection: quantitative safe geography audit v1.219

**Question:** Compared to a separately sourced 17,883-island physical geography compilation (Weigelt et al. 2013; DOI 10.5061/dryad.fv94v), how do the 5,401 island nodes retained in Structural differ in island size, mainland isolation and climate? Barreto et al. 2021 (DOI 10.1098/rspb.2021.1879) excluded IUCN mammal-zero islands before creating their 5,592-island island×mammal map matrix.

The v1.219 archive input is **not the consumed mammal response**. We reuse the frozen response-safe 17,883-row Weigelt island geography artifact, SHA-256 ebb4b54c..., and the original frozen 5,401-row Structural *geographic state* artifact, SHA-256 5a04e8b6..., solely to recover node IDs. Exact ID matching is required; if mismatched, STOP. The files contain no species-by-island response or prediction scores. The results include only aggregate medians/interquartile ranges in the full/sampled/nonselected Weigelt frame, two log scale standardized mean differences, and coordinate/archipelago metadata completeness.

**Hard caveat:** Nonselected in the Weigelt frame DOES NOT mean biologically mammal-empty. It includes islands excluded for unconfirmed geographic/biotic attribution, different source GADM versions, missing covariates, and the 191 Structural-specific quarantined/overlap nodes, as well as mammal-zero islands. Thus differences measure overall geographic/sample-frame selection, not causal effects from excluding mammal-zero islands alone. 17,883 is a historical Weigelt >1km² geography universe, not a perfect contemporaneous all-island frame equivalent to Barreto's. Coordinates in the safe Weigelt table are missing for 6,337 islands; no complete physical kNN graph can be rebuilt from that source under this protocol.
