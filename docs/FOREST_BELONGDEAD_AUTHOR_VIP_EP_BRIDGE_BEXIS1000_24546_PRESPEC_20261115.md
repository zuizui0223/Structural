# BELongDead original VIP–EP identity bridge: BExIS1000 plus original deadwood volume inventory BExIS24546 (prebiology freeze, 2026-11-15)

## Where the original data stopped
CC BY4 BExIS31123 original: 59,850 observation rows, 30 `PlotID` source forest plots in three Exploratories, 379 unique experimental `TreeID` candidates, 13 `TreeSpecies` host resources and 8 `CollectionYear` values. **No original beetle capture/taxon values used.** Exact source plot overlap with two BExIS inventories `3546` = 0/30, original author-cited `18270` = 3/30 (`EP` in original 18270, 150 EPs). 30925 source version1 could not be verified in published API; no data retrieved. No ID conversion or biological effect was calculated.

**Official Biodiversity Exploratories design** describes 300 experimental plots (EP) and *nested subsets* of medium- and very-intensive (VIP) plots. **Official public BExIS dataset 1000** is named `Basic information and coordinates of field plots of the Biodiversity Exploratories project`; its publisher explicitly says plot coordinates are deliberately rounded to two decimals and plot identities are documented. **Never read, report, map or export these location coordinate values.** BExIS source dataset 1000 version7 is listed on the public dataset page; if the actual BExIS dataset metadata gives a different current published version, use the publisher's explicitly returned version and record it, not fabricated IDs. Source 1000 may or may not have an authoritative VIP→EP link; only named original source fields establish it.

**Official BE forest-structure catalogue** identifies BExIS24546 v1 as `1st Dead Wood Inventory of 148 forest EPs, item volumes, 2012`. The original BELongDead JAE author's data availability explicitly cited **24546, 18270, 30925** for forest structure. The 24546 2012 deadwood inventory is **NOT equivalent to living conifer/broadleaf source-tree basal area** and cannot substitute for measured living host supply. This cohort is earlier in time than some 2010–17 beetle surveys.
