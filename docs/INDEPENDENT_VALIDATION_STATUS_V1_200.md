# Structural v1.200 — independent validation status, not another model rescue

## Exact-source checklist distribution stopped before evidence

Hébert et al. 2021 (DOI 10.5061/dryad.rfj6q579r) still has nine originally frozen file links visible on Dryad's dataset landing page. The same files were probed under explicit no-response contracts:

- v1.188 failed on the first direct download before opening CSV headers;
- v1.198: all nine legacy API URLs returned 401 to HEAD; all nine page-linked `file_stream` URLs returned 403; **0/9** HEAD candidates;
- v1.199: a single `Range: bytes=0-0` GET was authorized per exact frozen URL, with acceptance only of HTTP 206 and a valid Content-Range before reading even a header byte. API routes returned 401, public page-linked routes 403: **0/9** range candidates, **0 bytes** actually read.

Neither checklist species headers, island names, nor a single 0/1 site×species label was decoded. No ecological scoring occurred. This **does not** reject an ecological hypothesis; it closes *this automated exact-source transport route* pending genuinely independently verifiable access to the same exact files.

## What the best existing result actually tells us

The ultrarare mammal model's C−R3 presence-specific point estimate is −0.59626. The mean rewired C−R3 is −0.53773. The graph-specific point increment is −0.05853, or 9.82% of the original improvement magnitude. The other 90.18% survives degree-/edge-length-bin rewiring. These are point-estimate ratios of predictive log-loss differences, not 90% biological source movement.

This is a **coordinate-derived kNN graph predicting IUCN polygon-derived and historically augmented mapped labels**. It is not a species-movement or contemporary rescue mechanism. The frozen 212-species response-free source turnover diagnostic was adverse to individually differentiated source territories (actual−null beta −0.262, 95% interval −0.317 to −0.208). The independent BALA temporal source-loss primary was also non-supportive. No combination of these establishes source-node management priority.

## Next independent data line: what would actually improve knowledge?

An independent dynamic system is useful only if it resolves (i) what the animals/individuals did, (ii) which unsampled or apparently absent patches were genuinely surveyed, and (iii) the pre-outcome source state. Two potential sources have *better biological endpoints* but are not currently approved:

- **Tidewater goby** (Dryad 10.5061/dryad.vdncjsxs9): 190 estuarine habitat units, 813 eDNA samples in 2016–2017 with a published spatial neighborhood matrix and detection-aware dynamic occupancy analysis. But only two annual waves and a published colonization rate around 0.085 imply limited transition-event power. Published spatial-neighbor effects mean a copy of that result is not a new mechanism.
- **Black/Virginia rails** (Dryad 10.5061/dryad.8w9ghx3h8): 273 surveyed wetland units across repeated breeding surveys in 2002–2016, detection and unsurveyed denominators, plus seasonal recolonization observations and lagged isolation measures. Mechanistically richer temporal data, but no confirmed independent measured dispersal edges, and this is a habitat-fragment rather than a literal oceanic-island system.

These are *metadata descriptions, not results from Structural*. Source/site identifier coverage and node/geography availability must be inspected before a separate design freezes the actual endpoint and permissions. An unobserved process cannot be made observable by adding another network metric.

**Decision:** Keep GEB on scientific HOLD for biological dispersal/colonization/rescue claims. Stop same-endpoint Dryad transport retries, exhausted ALA, BALA, SW Finland, boreal birds, same-map reruns and eBird. The next gain must be independent biology, not a new rhetorical name.
