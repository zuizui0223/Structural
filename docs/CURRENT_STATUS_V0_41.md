## TTF relationship

TTF does not sit inside Structural admission.

The order is:

```
Structural admission
  -> separately frozen within-system confirmatory protocol
  -> within-system adequacy / portability evidence as applicable
  -> independent TTF deployment and species-disjoint transfer test
```

TTF may not:

- select a Structural system because transfer looks promising;
- rescue a Structural pilot failure;
- turn a burned pilot into transfer evidence;
- merge its genetic empirical denominator with Structural;
- retroactively validate a within-system mechanism.

The current TTF genetic result remains conceptually useful as evidence that within-species detectability and cross-species transferability are different properties, but it is not a Structural replication.
