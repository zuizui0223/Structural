# BELongDead 13 deadwood tree species × local stand-tree supply (BExIS 3546) — independent original forest inventory source gate, 2026-11-15

## Main research advance
In original BExIS [31123](https://www.bexis.uni-jena.de/ddm/data/Showdata/31123?tag=1), authored BELongDead field data, exact public CC BY4 and source CSV 8,103,493 bytes with SHA256 `73f759e8ce8b2e302dbbc5bddc947252caeb5b0b1fb15aa0280e732f7a31617e` were verified in [Actions #43702414237](https://github.com/zuizui0223/Structural/actions/runs/43702414237). The complete original 17-column source has **59,850 long observation records**, **3 Exploratories, 30 original (Exploratory,PlotID) plots, 379 nested (Exploratory,PlotID,TreeID) experimental wood units, 13 original TreeSpecies labels, 2943 nested tree×CollectionYear metadata groups across 8 years**, with ZERO source host identity conflicts. It contains TrapID/Traptype and explicit CollectionYear; no raw beetle identities, abundances, taxon values or guild response opened/scored. These rows are not independent sample units; 379 is actual wood-unit *ID candidates*, not evidence of equal or complete sampling effort.

The candidate follow-up asks a substantially different ecological question from the published 2016 host-tree effects and prior Finland deadwood total amount: **does an experimentally supplied 13-host-wood type attract/draw locally specialized saproxylic beetles when the same tree type is rare in the surrounding source forest?** This is a `source pool × experimental resource type` prediction test. To be identifiable we need measured **stand-tree species composition** in matching original 30 plots, original forest inventory years, and 2010–2017 beetle survey effort (including actual zero-sample years).
