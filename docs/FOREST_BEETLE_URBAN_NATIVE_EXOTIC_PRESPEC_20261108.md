# 事前固定した探索検定：森林景観内の都市化と外来甲虫の出現比（2026-11-08）

## 研究目的（原データの効果を開く前に固定）

島嶼で確認した種特異的な供給源配置・人為資源の利用という問いを、森林の**水平的な生息環境**に持ち込む第一段階。ただし現在のNardi et al. 2026の13景観は港湾導入・移動実測を表すものではない。元論文が主題とする監視設計から独立した新仮説を確証するデータではなく、再解析の**探索的な候補**として扱う。

**固定する唯一の主コントラスト：** 各景観内部で `urbanization_index` が高いトラップほど、記録された甲虫分類ラベル中の **Exotic 検出割合**が増えるか。

- 原本：Zenodo v3 DOI `10.5281/zenodo.17044394`、`bio_cast.txt`（207×303、301分類群の0/1捕獲有無）、`bio_data_trapscale.txt`（3,215 `SITE,CELL_ID,SPECIES,STATUS,N`行）、`env_data_trapscale.txt`（207 `SITE,CELL_ID,composition,configuration,urbanization_index`行）、`env_data_sitescale.txt`（13景観 `forest_2000`ほか）。元MD5・結合IDを固定して使用。
- `STATUS` は各**景観×分類ラベル**で定義。Native/Exoticの一意なラベルは全球で固定しない。7分類ラベルが景観間で異なる在来/外来状態をもつことを原本で確認済み、同一景観内で混在0。
- 正の `N` を含む長形式の出現セル×分類群は、広形式の0/1と**3,215/3,215完全一致**。主応答は N の絶対量ではなく、この存在インシデンスだけを使用。原本 `N` 合計61,769と論文本文61,755（差+14）は未解決だが、存在応答への影響を避ける。
- 対象観測単位は**207採集セル**、独立した推論単位は**最大13景観**（8か国、景観が各国で独立かは未確認）。0セルを種の非存在とみなさず、原標準化トラップでの非検出として扱う。
- 主応答 `exotic_detected_label_share = E/(E+N_native)`。各トラップの異なる種名（ラベル）を一度だけカウント。分母ゼロならそのセルを応答欠測扱いし、各景観で欠測セル数を報告。
- 主説明変数は原本のトラップ `urbanization_index`。単位・符号の名称は元資料のまま保持。各景観内で中心化・標準偏差1にし、各景観の OLS `exotic_share ~ z_urbanization` 傾きを求める（該当尺度で被捕獲種の外来比率が高いか）。少なくとも10応答セル、8以上の互いに異なる都市化値、十分な分散がある景観のみ事前基準として通す。適格景観が8未満なら本主解析は停止。
- **主統計量**：適格景観ごとの傾きを**景観間で等重み平均**。一景観に16セルあっても16独立森林と呼ばない。各景観の傾きの正負、最大値、再現数を同時に示す。
- **不確実性**：景観単位で10,000 bootstrap（n=eligible landscapes）、景観内部で `urbanization_index` をセル間にシャッフルする9,999回の**探索的**二側置換判定。景観内の空間自己相関を無条件に除去できず、厳密なランダム化試験ではない点を明示。
- 感度解析はひとつだけ：異なる都市化インデックスの値域を確認し、within-site傾きが1景観を除いて符号を維持するか。**`forest_2000`と exotic share の森林景観間の相関は本ターンの主検定では採点しない**。森林量は複数景観同士の交絡原因となるため、景観内固定効果に吸収している。

## 解釈と停止条件

- **仮説の支持判定**：景観間等重み平均傾きが正、かつ景観bootstrapの95%下限が0を超える。外れ値・適格景観除外を変えて陽性を救済しない。支持外なら不支持／不確実と明記。
- ポジティブでも、森林連続性の機構、導入経路、個体の移動、絶滅危機、異なる森林バイオームへの普遍性、林冠と下層の垂直ニッチ、温暖化からの逃避は識別できない。
- 元論文と同一原本を使うため、完全に新しい生物学的独立追試でもない。確認的評価には別の甲虫調査系と事前固定応答を要する。
- この解析は既存の島嶼哺乳類GEB凍結ホールドアウト、BALA/SLAM、タイColeopteraの実測肯定結果を変更しない。eBirdは使わない。
