# Source-adapted retrospective analysis: matched within-plot five-host emergence heterogeneity

## Timing and classification
Frozen for a **distinct, one-test within-plot association** after the already-exposed 2026-11-22 LOPO prediction analysis and host-specific descriptive positive fractions, but **before executing the new omnibus statistic or its conditional permutation**. This is explicitly post-outcome/exploratory and NOT an untouched prospective test. Do not use this test to rescue the prior unsupported external-plot predictive gain, and do not claim new causal species-specific preference or new field sampling.

## Verified original source/grain
Publisher original user-provided ZIP `R skript and raw data.zip` SHA256 `8c6e822866207a3398d6ce32fd35b6786713472ea87c2c1f3267984ebb79500d`, 11,201 B. Original `PlotSpeciesIndiv_3.csv` has 61 physical `Plot` IDs with `Category4` in {Agri, Reg1, Reg2, Old}; original `PlotLogSpeciesAbundancesDensity.csv` has 300 unique physical Plot×Host records, of which 59 physical plots have all five offered host IDs and two are incomplete (4+1 logs). These 59 matched plots (=295 recorded logs) are the fixed primary sample. Remaining 2 plots are NOT converted to negative observations, nor used to define a second favorable population. Five literal host IDs: CACAO, FERNAN SANCHEZ, GUABA, MASCAREI, SAPANILLO. Original physical log `Indiv==0` denotes no adult emergence detected in that source record, NOT biological inability to colonize.

## One fixed question, one fixed primary statistical test
**Question:** *Within a physical plot sharing the same broad recovery-stage context, is observed adult beetle emergence equally distributed over the five standardized offered host-tree types?* Preserve each original plot's total number of host logs with observed emergence and randomly permute the five original host labels **within each physical plot**.

- Source row input: `Plot,Host,Indiv` only, with plot/context solely for describing fixed group sizes; do not open species-by-host-by-stage aggregate as plot-level species composition.
- Original binary response (Y_{ih}=1[mathrm{Indiv}_{ih}>0]) for each matched physical plot (i=1,ldots,59) and offered host (hin{1,ldots,5}).
- Statistic: **Cochran's Q** for the 59×5 matched binary matrix, defined exactly by (Q=(k-1)(k\sum_h C_h^2 - T^2)/(kT-\sum_i R_i^2)), k=5, column successes (C_h), row successes (R_i), grand successes (T); scientific STOP if denominator=0. For the conditional randomization, enumerating 59 independent permutations is infeasible, so use exactly **19,999 Monte Carlo permutations**, `numpy.random.default_rng(20261122)`; shuffle the five values independently within each physical row, preserve row sums, compute (Q^*), return (p=(1+#(Q^*\geq Q))/(19999+1)) (one-sided because Q>=0). Do not substitute an asymptotic χ² p to claim significance.
- Primary effect size: the 5 original host-specific success fractions and **unselected omnibus dispersion** `max(host rates)-min(host rates)` labelled descriptive; not a pairwise confirmatory effect. A sampled plot is the independent physical cluster, not 295 independent forests or 10,650 adult beetles.
- Auxiliary source diagnostics: original 59 plot recovery stage counts; 5 host counts and within-plot success-count distribution, published total adult-count parity and source missing log caveat. Optional *descriptive* four-stage host-success proportion tables, with **no new stage-specific p values**.
- Fixed null reference and limitations: conditional within-plot label exchangeability requires treating the five log positions, origin conditions and observation effort as comparable. The original source does not document host-log randomization or full variation in log size, decay, microclimate or local presence; a low p therefore supports a nonrandom within-plot observed association under this null, **not randomization-based causality**, colonization failure, host-density separation or portability.

## Interpretation firewall
The old E0→E1 leave-plot-out predictive log-loss improvement +0.030624 (95% conditional plot-bootstrap [−0.005204,+0.064390], p=.0906) remains formally **unsupported**, as does a multi-region effect. This new conditional association addresses a different estimand; a significant paired contrast would show **host-label sorting inside observed plots** but NOT a useful out-of-plot predictive increment. Tree host is completely confounded with source assigned wood density (five levels one per host). The original published Falconí-López et al. 2026 article already analyzed beetle richness, abundance and host networks; any newly derived matched-binary contrast is a retrospective methodological addition, not the first host-dependence discovery.
