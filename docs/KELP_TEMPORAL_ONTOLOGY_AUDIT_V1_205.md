# Temporal-selection and source-state ontology audit v1.205

Castorani et al. (2017) delineated 469 patches using Landsat kelp habitat and synchrony from 1984–2011. These patch boundaries cannot be treated as an outcome-independent sampling frame for a genuinely prospective split beginning in 1996. This is a restriction on a new forward validation, not a criticism of the published retrospective analysis.

Patch source fecundity was predicted from diver-calibrated canopy biomass. The primary specification assumed no fecundity in patches with undetectable surface canopy. The authors also tested a nonzero-intercept alternative with qualitatively robust conclusions. Thus the source state is a canopy-derived proxy, not independently observed reproductive shutdown. Lagged donor canopy may still predict later recipient turnover, but it would not independently validate fecundity failures.

Wanner et al. (2024) considered 117 kelp-bearing ROMS cells from 135 physical model cells. No pre-1996 source universe has been certified. The 117-cell restriction may be fine for published retrospective synchrony description but must not be silently reused as an ex-ante 1996 prediction universe.

## Public catalogue entrypoints

The SBC LTER catalogue lists three package pages: knb-lter-sbc.101 (patch definitions), knb-lter-sbc.102 (patch area, biomass, fecundity), and knb-lter-sbc.103 (spore transport time). These are catalogue route identifiers, not verified DOI-version matches or data table headers. EDI REST API authentication is required; no authenticated EML/entity response was read.

## Deterministic decision

Fresh 469-patch forecast: STOP (future-defined geometry). Fresh 117-cell forecast: STOP pending cutoff-qualified inclusion (ever-kelp selection). Direct biological source cofailure claim: STOP (canopy-derived proxy). Cross-grain 469-to-117 join: STOP (no identity crosswalk). Historical description and engineering: retrospective only, never new confirmatory biology.

## Admissible next step

Use a physical node set defined without target-future biological data; donor production state lagged and clearly distinguished from canopy occupancy; separable target 0-to-1 and 1-to-0 outcomes with observational denominators. Do not open data before response-opaque IDs, times and exact source versions are verified. No original mammal or kelp biological response was accessed here.
