The 2014–2018 historical woody source QA STOP and the 2019–2023 seasonal/effort STOP at 10<12 paired site-years remain unchanged.

## Predeclared cross-sensor identity and endpoints

1. Both data providers are independent original observation channels: `neonDivData 0.3.1` for **source site×plot identity only** and original official 2026-08-05 NEON 81-site context; separately public CHMv2 under `dataforgood-fb-data`/Source Cooperative, and published VST 42-site family Git commit `3391e702e7be80a3f049c905782661f043be8db8`. All individual source coordinates, site/plot, tree records, species, pixel arrays stay runner-private. Only aggregates exposed. **This is NOT independent validation of the ecological response**; the same field sites would be used.
2. Original VST event-filter from previously audited 73 cohort exactly: source `sampled_with_records`, area_trees>0, original `nlcdClass` forest, 2019–2023 year, `height>0` finite, `stemDiameter>=10`, living `single/multi bole tree`, original `size_height_ok` if present, unique `individualID` per site/plot/year (if multiple stems choose **maximum valid height** for one physical individual, fixed prior to numbers). Require >=3 such distinct individuals. `VST_p90_height_m` is empirical 90th percentile of these distinct tree heights; it is not equal to site mean tree height or tallest possible tree.
3. For **each original site×plot** with repeated VST years choose **the valid VST survey year closest to 2020**, ties choose the **earlier year** (first 2019 if tie between 2019/2021), independent of canopy pixels. A plot is one independent spatial observation; repeated VST plot-years are NOT independent. Original candidate VST 73 plot-years, unique sites and plots counted independently; if 73 source QA support cannot be reproduced, stop.
4. Match by exact original site×plot label to author's NEON `basePlot.div/.brd` original plot coordinate already audited. Read the SAME published CHMv2 40m×40m pixel method already frozen in [pixel QA prespec](FOREST_MACRO_NEON_META_CHMV2_PLOT40M_PIXEL_QA_PRESPEC_20261114.md). CHMv2 `>0` pixel p90 and fraction>=20%, positive pixel count>=25; all 0/nodata and poor cover excluded, never treated as 0 m tree absence. Original annual plot×year is NOT temporal replicates of static CHMv2.
5. If matched field+CHM source has fewer than **10 NEON sites**, fewer than **25 distinct original plots**, or fewer than **6 NEON domains**, the cross-sensor numerical concordance is STOP rather than choosing more favorable time lag, plot width or pixel threshold. NEON 2019–2023 original source sampling scene year and official plot polygons are still not established.
6. **Single primary calibration statistic**: Spearman `rho_site` between per-NEON-site medians of VST field P90 and CHMv2 positive-pixel P90, one value per matched site. Report site-bootstrap 4000 percentile 95% CI (ties handled by ranks, fixed seed 20261114). Always report sign and CI. Do not treat 73 field plot-years as independent forests. Supplement: plot-level median signed difference `CHM_p90 − VST_p90` and median absolute difference (m), site-weighted site median absolute error, number with tile-date window overlapping original VST year (source tile date window **not** source pixel acquisition), number of matched original plots with >=2 plots/site for within-site interpretability. No p-value selection or "spatial validation confirmed" if CI covers zero. Never claim these are identical footprints: CHMv2 40m square ~1600m² versus field tree sampling variable `area_trees`.
7. A scene date-window overlapping VST survey year is descriptive only. It does NOT authenticate exact pixel acquisition year, and CHMv2 source is not annual. Report whether tile date window overlaps field year as a source diagnostic; never use date overlap as a post-response way to fish a higher rho.
8. No taxonomy, species, beetle abundance, plant cover, community beta, past PREDICTS or NEON outcomes opened. No ecological effect of height fitted here. PREDICTS original 39-study `+0.0942`, 31-study distance sensitivity `+0.0847` and 7-site cross-taxon temporal null `−0.0664,p=0.536` retained; eBird/TinyFish unused, Draft PR #469 not merged.

**Go/stop decision after source validation:** even a strong field-vs-CHM correlation only establishes rough spatial height-proxy agreement. To use CHMv2 for a new ecological *exploratory* comparison, separately fix a nonannual sampling epoch and NEON effort-matched geographic strata before opening new species response. This stage does not authorize reinterpreting 2019–2023 temporal turnover as canopy-height effects or relaxing the former 12-siteyear VST gate.
