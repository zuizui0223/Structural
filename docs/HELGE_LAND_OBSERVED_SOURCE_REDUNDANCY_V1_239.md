# Helgeland v1.239 — Recipient-level *observed* natal donor redundancy

**Biological question.** When islands receive an equal number of observed natal immigrants, do their recruits originate from many similarly contributing natal islands, or from a single dominant natal source? Does one well-connected natal population also supply **multiple** recipients, making them share a documented supply dependence?

**Data restriction.** A source-locked published v1.231 freeze already records every ID-deduplicated `stage=nest` birth island → next-year `capt/obs` destination in an eleven-island Norwegian house sparrow archipelago. This script reads that frozen JSON only, not raw individual bird responses, not Dryad pedigree data and not original GEB mammal heldout. Counts of documented migrants are historical 259, bridge 28 and later 173. The 2025 pedigree files have immutable IDs and five file SHA256s, but the Dryad API download gave HTTP 401 and public-portal transports gave HTTP 403. **No offspring fitness values are available or imputed.**

**Primary descriptive metrics predeclared before THIS code replay but after original published outcomes and v1.231 network were exposed.** For every one of the eleven recipients in all three cohorts, count immigration from every other source, existing natal resident next-year resightings, fraction immigrants among all known first-year recruits, total distinct observed natal sources, inverse-Simpson donor number (an effect of skew), Shannon donor number, highest donor share, and the exact probability two distinct observed immigrant IDs were born on the same source island. The latter uses `sum n_s(n_s-1)/(N(N-1))` and reflects finite lists rather than treating immigrants as independent island systems.

A cross-recipient pair receives a source-sharing score `sum_s p(s|A)p(s|B)`, the probability that two independently drawn *recorded immigrants*, one into each recipient, share the same observed natal source. Emit all recipient pairs, not only striking examples.

An illustrative source-deletion bookkeeping subtracts recorded immigration edges from a natal source. **Do not call this a counterfactual population-extinction or rescue prediction.** It does not estimate how destinations adapt or whether remaining sources replace lost flows. Origin-population size is not measured fully: total marked nestlings per donor in the observed cohort is only a coarse sampling-exposure proxy and cannot adjust differential detection or true reproductive success.

Previously published natal dispersal and immigrant fitness findings (Ranke et al. 2021 and Saatoglu et al. 2025) are not independent replication and must not be represented as novel. A new mechanism would need prospective changes in source activity, field-verified immigration and destination demographic response with the pre-frozen reference/heldout gates. GEB scientific HOLD unchanged.
