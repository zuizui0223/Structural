## Biological question

We know host labels predict different within-plot probability of **recorded adult emergence**, a previously outcome-exposed local association. New question: *among logs with at least one recorded emerged adult*, is offered tree Host still incrementally predictive of **per-log detected species richness after conditioning on adult sample size and original forest context**? Because adult count may itself be affected by Host, this is a conditional **predictive** quantity, not a total causal Host effect. No abundance-standardized richness can be estimated without per-log species abundance distributions.

## Single frozen model and endpoint

Use original matched physical plot IDs as leave-one-physical-plot-out units. Only source logs with Indiv>0 are *eligible response rows*, keeping every positive log within a plot together. Response for each: log1p(Spec) (natural log). Predictor baseline E0: Category4 categorical, History categorical, Latitude/Longitude/Elevation numeric and log1p(Indiv) numeric. Extended E1: exactly E0 plus Host as a five-level categorical factor. WoodDensity excluded because exactly one recorded value per Host; no stage interactions or other feature search. Within each fold, training-set-only OneHotEncoder(handle_unknown="ignore"), StandardScaler for numeric, Ridge(alpha=10.0, fit_intercept=True). No fitted penalties/feature selection. Loss = mean squared error of log1p(Spec) over eligible held-out logs, then mean of plot losses across 59 plots **equally**. Improvement D=Loss(E0)-Loss(E1), positive is better.

Fixed uncertainty: 4,000 bootstrap resamples of the 59 original plot deltas for percentile 95% interval; 9,999 independent random sign flips of plot deltas for two-sided p with +1 correction, numpy RNG seed=20261122. Report counts positive/negative/zero and actual denominator. Scientific support only if D>0, lower bootstrap bound >0, and p<0.05; else NON-SUPPORT, including any negative sign. This is model and sampling conditional uncertainty: overlapping training sets and one national study do not provide independent forest-region replication.

Additional noninferential diagnostics **only**, not more p-values: observed 5 Host positive-log counts, descriptive conditional mean Spec by Host; arithmetic identity E[Spec|Host] = P(Indiv>0|Host) × E[Spec|Indiv>0,Host] using matched-plot source records; positive logs and total adult sample counts. This distinguishes an **emergence gate** from **post-emergence count sampling**, not a proof that one biological process exclusively caused richness. No stage-specific tests, no selected host pair tests, no secondary abundance/richness model tuning.
