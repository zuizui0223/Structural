## Scientific interpretation gate
Physical-site grouping is **observation-hierarchy validation**, not a new positive ecological result. The question is whether forest-to-forest differences in host-tree affiliations remain after repeated observations are correctly pooled. This still cannot prove that measured conifer/broadleaf availability, canopy, deadwood resource amount, local temperature or forestry cause the pattern. Those environmental mechanisms require source plot covariates with author verified site IDs and comparable survey year/method.
