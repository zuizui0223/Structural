# Dual-isolation source-pool hypothesis v0.55

## Ecological revision

The island programme no longer treats extreme mainland distance as the universal switch that determines whether occupied insular sources matter.

The completed evidence instead motivates a two-axis view of island isolation:

1. **external isolation** — separation from major mainland/continental source areas and historical land connections;
2. **internal source isolation** — separation from the focal species' occupied source pool within the island system.

These axes can diverge.

A remote island can remain internally source-rich if the focal species occupies accessible neighbouring or stepping-stone islands. A geographically near island can be internally source-poor if the focal species is absent from the surrounding insular source network.

The next fresh test therefore asks whether **internal source isolation is an independent ecological axis**, not whether remoteness universally amplifies it.

## Why this is a change from source-pool handoff v0.1

A-Islands generated the original handoff idea: species-conditioned source structure became conspicuous in the remote tail.

The independent 318-island mammal stress test then showed two things simultaneously:

- adding within-archipelago occupied-source information improved heldout log loss descriptively overall;
- the predeclared prediction that this gain would be stronger in the extreme continent-isolation tail was unsupported.

That stress result does not confirm a new hypothesis. It changes what must be tested next.

The v0.1 source-pool-handoff object remains immutable historical provenance. v0.55 supersedes it only for **future fresh tests**.

## Four ecological states

The conceptual design has four states:

| External isolation | Internal source state | Ecological interpretation |
| --- | --- | --- |
| low | source-rich | mainland access and insular source support both high |
| low | source-poor | geographically accessible but the focal species lacks nearby/connected insular sources |
| high | source-rich | remote from mainland but buffered by occupied insular sources |
| high | source-poor | isolated from both mainland and occupied insular sources |

The important prediction is not a fixed ranking of mainland distance.

It is that source-rich versus source-poor states can differ **after external isolation has already been represented**.

A future genuinely response-sealed system must freeze a strong reference before response access.

No extreme-isolation interaction is required for primary support.

## Mainland remoteness is now context, not the switch

External isolation remains biologically important.

But v0.55 assigns **no universal sign** to:

    external isolation × internal source-pool gain

An extreme-isolation tail may be reported as a descriptive sensitivity if frozen before response access, but it cannot rescue a failed overall primary.

This explicitly prevents a return to q75 threshold hunting after the 318-island result.

## Prospective moderator 1 — archipelago permeability

Physical island layout determines whether occupied neighbouring islands are plausible sources or only map neighbours.

Before any response opens, a future test may freeze a response-independent permeability coordinate derived from geometry, such as:

- nearest-neighbour spacing;
- stepping-stone density;
- graph reachability under frozen radii;
- surrounding land/island amount.

Prediction:

> internal source-pool information is more useful in more permeable archipelagos.

This is secondary. It cannot rescue a failed overall source-pool primary.

## Prospective moderator 2 — dispersal mode

Island biogeography has long recognized that the ecological meaning of isolation depends on dispersal ability.

If an external taxonomy/trait source can be frozen before response access, v0.55 predicts:

- higher-dispersal taxa: stronger information in the **present occupied source pool**;
- lower-dispersal taxa: relatively greater importance of **historical connection / legacy**.

For mammals, volant versus non-volant is a natural prospective contrast. Other taxa require independently justified trait groupings.

No grouping can be selected after response exposure.

## Prospective moderator 3 — source saturation

A-Islands suggested that very widespread species can become source-saturated.

v0.55 therefore freezes a secondary prediction:

> incremental internal-source information declines with increasing training-only global occupied breadth.

The breadth variable is derived from training response only and must be identical across heldout comparisons.

Again, this secondary cannot rescue the primary.

## Connection to island-biogeography theory

This formulation is compatible with the broader literature in which isolation includes more than mainland distance: stepping stones, surrounding landmass, currents, archipelago structure and species dispersal ability can all alter effective isolation.

The conceptual advance sought here is narrower:

> **the isolation of an island is not fully specified until both the external geographic setting and the focal species' internal occupied source context are defined.**

Relevant theoretical context includes:

- Schrader et al. 2021, *Biological Reviews*, DOI 10.1111/brv.12782;
- network-based island roles and stepping-stone structure in archipelagos, DOI 10.1111/j.1365-2699.2011.02628.x;
- dispersal-mode dependence of island isolation effects, DOI 10.1111/jbi.15038.

These references motivate the prospective moderators; they do not supply empirical confirmation for Structural.

A v0.55 confirmation must come from a genuinely new response-sealed system.

Before response access it must freeze:

- the complete response-value domain;
- response-independent island geography and external isolation;
- generic archipelago permeability;
- v0.31 pilot/confirmatory partitions and estimability gates;
- v0.42 response-quality rules;
- the R0→R3 reference ladder;
- the C internal-source operator;
- any dispersal/permeability/source-saturation moderator.

A-Islands and the completed 318-island mammal stress test cannot enter that denominator.

## Strongest current ecological statement

The current cross-system evidence supports a change in how the question should be framed:

> **External remoteness and internal source isolation are different ecological dimensions. Occupied insular source pools can contain information beyond strong island-state descriptions, but mainland remoteness alone does not determine when that information matters.**

The fresh empirical test of that two-axis formulation has not yet occurred.
