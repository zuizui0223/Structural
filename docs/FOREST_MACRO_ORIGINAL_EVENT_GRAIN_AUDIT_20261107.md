# 全球森林マクロ生態学：原Event粒度と独立性の監査（2026-11-07）

## 目的・達成条件

森林群集×森林構造の全球的な関連を分析するため、独立した地理的森林調査単位を特定する。Event（採集回）、locationID（出版者の地点ラベル）、座標値、物理調査区画、森林・生物地理的独立反復を混同しない。今は原観測入力の品質監査であり、森林構造の統計的効果を推定したものではない。

## 監査結果（2026-11-07、作業ブランチ）

- 公開PREDICTS地点要約からの**厳格森林候補4,920地点、315研究、64か国、7森林バイオーム、7 Realm**は既に検証済み。ただし参照・改変を同一研究×方法×分類群で比較できる1,145地点・39比較層は、20か国・わずか2森林バイオームに偏る。これらは**森林構造応答モデルに投入済みの標本数ではない**。
- 別経路でGBIFの18原モニタリング候補を固定し、2019–2026年の索引記録を持つ7データセットを抽出。原採集Event表の原ファイル（出版者DwC-AのEvent coreのみ）を今回4/7データセットで取得・検証した。**原Event行合計910**。

**注意：36座標ペアは36独立した森林でも36採集ポイントでもない。** タイの公開方法記載では2森林それぞれ9採集ポイント、計18ポイント。出版者の`locationID`は各データセットで2つ（森林単位）。原座標36ペアは甲虫・膜翅目で**全36ペア一致**し、2つの分類群は同じ地理的調査枠を共有する。独立地域の再現2件とは計数しない。森林内の地表／林冠、採集日、同一点における座標の微差は元プロトコルと照合して最終的なサンプリング単位を定める。

同様に米国の14座標ペアと28 Events、ノルウェーの306座標ペアと306 Eventsは、**座標候補の数**であり独立森林区画数の保証はない。`locationID`欠落を理由にEvent coreまで読めなかった扱いにせず、原Event数の確定と区画数の未確定を別列に記録した。

## 監査の実行検証

- GitHub Actions: https://github.com/zuizui0223/Structural/actions/runs/42330749632
- 成功した原本監査：7データセット対象、4 Event core確認、3取込STOP、原Event計910。
- Event core `meta.xml`のrowTypeとフィールド索引を解析して元Event表のみを読み、拡張Occurrence表は読まない。元アーカイブはSHA256で識別し、ダウンロード上限75MiBを適用。
- 同じ原調査の分類群別コピーが二重の独立生物地理反復にならないよう、タイ2データセットの5小数座標ペア集合を**一時メモリ内だけで**交差照合。共有36ペアのみ成果に残し、元座標・地点IDは保存しない。
- 2019–2026年の索引Occurrenceがあることは、2020年に現地で森林構造を測ったことを意味しない。原Eventの日付・座標精度・採集法を2020年構造地図に合わせて選定する必要がある。

## 現時点の科学的位置付け

### 実測から肯定的に支持されているもの

アゾレスBALA/SLAM地域パイロットの標高×起源別検出種数の負の関係、地表と樹上植生における反応差、既知島内で森林断片を除いた予測改善は別資料`FOREST_MACRO_RESPONSE_AND_MATCHED_METHODS_20261106.md`の実証結果として保持する。これは全球効果の独立再現ではない。

### この監査で成立した新しい、検証可能な結論

世界の森林標準化観測では「1 dataset = 1独立地域」「1 Event = 1区画」「1座標 = 1独立森林」の対応が破綻する実例を原本で確認した。タイでは2分類群×288 Eventが同じ2森林を共有し、米国・ノルウェーでは原Event coreに独立区画を示す`locationID`列がない。したがって階層を適正化してから環境予測を行う必要がある。

**現時点で全球の林冠高・構造偏差が群集構成を説明するという肯定的結果は存在しない。** 区画独立性・各採集年の環境一致・分類群の比較可能性を確定する前の全球回帰は実行しない。

## 次の実行ゲート

1. 米国・ノルウェーを含む原Eventの元採集プロトコルとID階層を確認し、`Event → plot → forest → region`の多対一対応を定義する。タイは18ポイントと2森林の対応を元資料から別途確認する。
2. 出版者アーカイブがブロックされた日本・リベリアについて、出典DOI・バージョンを固定し、公開済みの代替原本もしくは出版者配布方法を探す。スウェーデンは大容量に対応するEvent core選択読込方式を別途検討する。
3. 採集年と座標精度の条件に適合するものだけ、森林量・林冠高/構造・気候・標高に接続する。群集構成指標と地域外予測比較はその後、調査方法を層別して実施する。
