## What can be investigated scientifically — and the blocked causal mechanism

This original 13-host log experiment is a distinct independently published **ecological dataset**, but repeated 8 collection years and tree resources within the same 30 plots do not make 8×379 independent forests. The measured 2012 deadwood resource amount shows viable covariate support at **all 30 original physical plots**, meaning the hypothesis of **within-study plot variation in ambient deadwood amount** can in principle be evaluated. However actual variation in surveyed area and source point-transect sampling needs method/area correction before claiming absolute comparable ecological exposure across plots. Original published BELongDead papers already report host selection and decay-stage turnover, so merely repeating host-tree main effects adds little novelty.

The more biologically interesting **species-identity matching** question—whether experimentally provided host tree species elicit stronger beetle responses when that host is locally abundant in natural deadwood—**cannot yet be tested** because original forest wood `spec1/spec2` categories and source offered `TreeSpecies` labels have **0 exact literal string matches**, no author-defined code translation. Original 31124 “complete log” filtered source has 15 novel `TrapID` labels within fully known log+year parents; full original zero-capture trapping effort schedule is not independently verified. Do **not** impute missing capture rows as beetle absences, double-count mixed host volume, test only “matching” convenient 13-class subsets, or recode taxon labels to force a positive test.

**Current source-data outcome is a verified research-enabling positive (field measurement completeness and plot matched resources), NOT a positive beetle ecological association or independent confirmation of Finnish VD10 gain.** A next genuinely useful outside input is the original author's `spec1/spec2` code table and 2012 inventory surveyed area/plot transect multiplier, plus the source event/zero-capture trap deployment/TrapID crosswalk. These may be documented in BExIS original variable `meanings` or dataset-associated published methods and require explicit provenance if pursued. Do not search endlessly for a convenient secondary dataset; scientific inference must remain honest.
