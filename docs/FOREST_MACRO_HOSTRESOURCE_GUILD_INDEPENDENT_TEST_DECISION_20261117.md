## NEW execution 2026-11-17 — one source-conditional positive, not cross-country guild confirmation

A distinct original six-plot historical German deadwood experiment was actually reanalyzed with a frozen *leave-one-parent-plot-out* model after its source-only gate. Adding offered wood-host identity to a shade-only baseline reduced observed detected-species-composition Hellinger² error **4.54%**, across **6/6 plots**, two-sided exact block signflip **p=.03125** (n=6, minimum attainable). [Full executed result](FOREST_BEETLE_CHIU2023_STEIGERWALD_SIXPLOT_HOST_SHADE_SITE_HELDOUT_ACTUAL_RESULT_20261117.md). This is **single-forest, species-level, source-conditional** support, *not* independent cross-country *feeding-guild* transport or true causal resource supply.

## Primary scientific decision

**There is still NO independently completed cross-country biological confirmation that measured stand deadwood/tree-host resources transportably predict the relative guild composition of forest beetles.** The validated results are (i) Finnish single-source local deadwood added to spatially heldout Host_tree guild composition, small ΔHellinger² +0.00024237 (conditional signed-cell p=.015, nine cells), (ii) three-country source species-label-null Host_tree sorting D=.091059 (conditional p=.000333; many nonindependent sampling columns), (iii) German Piccini 8-site floor feedingguild original source heldout +11.70% relative error improvement, **exact site-signflip p=.09375, unsupported**. Source responses/trait ontologies differ and cannot be meta-averaged.

The more general original 39-study PREDICTS forest alteration taxon replacement is positive +0.0942 [+.0638,+.1253] but **forest structural resources or guilds are not the measured causal exposure**; Thai 18 station canopy catch excess is a different original abundance layer endpoint. New external discovery is specifically a *mechanistic independence gate*, not more evidence for those older observational effects.

## Why new automatic scoring would currently be wrong

A source-only Actions SUCCESS confirms provenance, checksum and method code executed; **it never constitutes a positive biodiversity response**. Exact source IDs, specimen-trap exposure including zeros, source guild ontology and independent field project lineages cannot be replaced by dataframe dimensions, header string similarities, nominal trap slots or detection-only records. Original country effect sizes use different response types and nulls (Hellinger² heldout loss, trait-label shuffle, Simpson beta, abundance), so averaging them would yield a non interpretable effect.
