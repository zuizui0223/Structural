# v1.222: Hopson experimental raw-data support audit, explicitly non-fresh

The previous v1.221 design-only check discovered two potential time-series experimental systems. v1.222 is a **separate, retrospective, outcome-exposed audit** of Hopson & Fox's archived 2016 raw data. It is NOT part of the Structural v0.31 fresh burned-pilot → confirmatory chain and cannot silently enter it.

Sources: [Hopson & Fox Dryad](https://doi.org/10.5061/dryad.n8d6s43), fixed [Zenodo archived mirror](https://zenodo.org/records/4960267). Frozen published MD5 checks for exactly two CSV files before any biological rows are decoded. README columns are date, day, jar.no, samp.vol, dil.vol, sub.samp.vol, eupl, tet; treatment layout is jar.no, metapop.no, patch.no, trt, time.block. Metapopulations are fourteen independent experimental replicates, each 15 ring patches; block 1 has sw=4/nn=3, block 2 sw=3/nn=4. These facts were checked from the author's public README and layout before the v1.222 analysis.

Scientific concern: a predator count of zero from a small undiluted sampled volume is **not proof of zero predators in the patch**. When counts switch 0→positive between observed jar dates this script explicitly reports *redetection after a zero sample*, never true colonization. Positive→0 is lost detection, not extinction. Predictors such as environmental prey and samples' detection volume must be incorporated if future robust transitions can be estimated. The treatment physically changes dispersal length, but this public CSV contains no record of which actual animal moved from which source to which target.

The executed source-locked output must report all treatments and time blocks regardless of perceived direction, without tests of favourable treatment signs, threshold optimization, species cherry-picking, or C−R3 scores. This source can be useful for observing whether there is enough temporal variability to design detection-aware models, not proof that a viability-adjusted source network produces more recolonization. A future independent source with true patch transitions and actual operator evidence still needs the Structural v0.31/v0.42 queue and a disjoint confirmatory partition. No historic STOPs rewritten.

If either pinned raw file is inaccessible or changes MD5, the Actions job fails; do not swap source versions or silently try new endpoints. Subsequent rescue claims cannot be rescued by an output-conditioned substitution.
