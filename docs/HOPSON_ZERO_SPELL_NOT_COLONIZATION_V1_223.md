# v1.223 — Disentangle a zero count from a true local disappearance

The original data contain 554 **observed zero-to-positive predator sample transitions** across 210 jars and 23 sampling visits per jar (14 independent metapopulations). These are repeated **samples**, not 554 independent colonization events. The v1.222 result opened all public raw outcomes in a retrospective non-fresh lane.

Before re-opening these same published source bytes, v1.223 fixes an exhaustive spelling of temporal detection episodes. Each consecutive zero-count run ending in a positive measurement belongs to **one recorded zero**, **two recorded zeros**, **three or more recorded zeros**, or **left-censored at the beginning of the experiment** (no recorded earlier positive). Runs reaching the final visit are **right-censored**, not artificially completed. Missing biological measurements (if any) break the run. No 0→positive event is promoted to new local colonization.

**Ecological purpose:** if many 0→positive events are just isolated zeros between two positive counts, the raw binary patch occupancy time series is not safe to use for rescue inference without an observation/detection model. Even a long zero-count run cannot establish extinction, because sample volume and abundance matter. The study only counted a small volume of each jar; pathogen/predator density stochasticity can generate zeros without complete local absence. Identifying actual emigrants/immigrants or serial negative sampling efforts would be needed for stronger ecological inference.
