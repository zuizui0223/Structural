## Research decision and evidence class

The principal macroecological hypothesis remains **measured local deadwood resource state × independently accessible regional saproxylic beetle pool** for **unseen-forest composition prediction** (see FOREST_BEETLE_MACROECOLOGY_RESOURCE_POOL_MATCHING_ROADMAP_20261123.md). No such empirical E2→E3 effect has been validated in existing Structural source datasets. The existing geographic/opportunity graph code is `analysis/forest_macro_global/source_pool_bridge.py`, including training-only donors, distinct island-vs-forest operators and unknown!=absence. **Do not duplicate it or assert its synthetic PASS is a biological result.**

**One NEW response-unopened question:** Does the original public French DATASAPROX standardized saproxylic-beetle surveillance archive contain geographically and historically documented **independent sampling projects** close to *later* sampled project locations? This is a **coverage/source-geography feasibility measurement**, NOT beetle species' occupied donor populations, forest connectivity or source-pool confirmation.

- Existing frozen metadata audit found **675,525 occurrence rows / 65,642 source producer×datasetName×eventID keys**, including **1,133 keys with conflicting sample-method metadata**; excluding those keys left **64,509** response-observed event keys. These source record counts must reproduce EXACTLY in this new gate or STOP. Do NOT reopen or alter historic vertical biology/STOPs.
- Read original occurrence core ONLY fixed metadata fields: ownerInstitutionCode, datasetName, eventID, year, month, eventDate, sampleSizeValue, sampleSizeUnit, dynamicProperties, decimalLatitude, decimalLongitude, georeferenceRemarks, coordinateUncertaintyInMetres, samplingProtocol. ***Never read/interpret scientificName, taxonID, taxonRank, organismQuantity, organismQuantityType or any response column***.
- Original event method consistency must use the exact previously frozen `(stratum,plot,trap model,type,treatment,bait,colour,year-month,duration)` rule and remove ALL original 1,133 conflicting source event keys. If recorded coordinates conflict for same otherwise-valid event, additionally exclude that event from geographic donor/target use and report how many; do NOT change the old original method conflict count.
- Geographic **STRICT** eligibility: original declared georeferenceRemarks='point' (not centroid), valid WGS84 lat/lon, original finite coordinateUncertaintyInMetres >0 and <=1000, year 1997–2025. **DESCRIPTIVE less-strict upper bound:** declared point and valid coordinates with missing/unknown uncertainty, kept separately as ineligible under primary. Do not infer precision from decimal places. Observational points and event counts are not physical independent forest populations.
- Collapse source events into distinct *original producer × original project × WGS84 coordinate × calendar year* sampling-location-year opportunities (exact float coordinates, no fuzzy site joins). Multiple traps/months cannot create additional independent locations. Source project names/coordinates are held private and only aggregate counts are exported.
- Candidate later sampled target opportunities: original calendar years **2016–2025** (10 complete inclusive source years). One historical donor is eligible only if its original survey year is **strictly earlier** than target year, and is a **different producer×project**, with an additional stricter report counting **different-producer** donors only. Exclude all observations sharing the target producer/project; same-year and later-year projects can NEVER be historical donors.
- Predeclared noninferred Euclidean-geodesic coverage bands: at least one eligible independent historical survey within **100 km** (primary *source geographic coverage metric*) and **200 km** (descriptive wider-range opportunity), computed from original point coordinates after source precision and temporal filters. Exactly `<=` radius. This is not a dispersal kernel or biologically optimized radius; species-specific dispersal cannot be inferred from a survey archive alone.
- Core outputs: counts of source archive rows/key conflicts/coordinate conflicts, eligible strict and unknown-uncertainty location-years and projects, number of 2016–2025 source target location-years eligible, fraction with earlier other-project donor at 100/200 km and earlier other-producer donor at 100/200 km, calendar-year aggregate anonymous support. No location IDs, site codes, project names, raw coordinates, taxon identities or any biological outcomes exported.
- The original source is **occurrence-only** and lacks a certified all-sample zero-catch frame. Neither a donor nor target's actual species membership is read, and no non-donor detection is treated as biological absence. A project having one eligible historical captured-beetle record is NOT an independently known accessible source pool for a specific taxon. Historical source 'access' is only metadata opportunity, not actual beetle dispersal evidence.
