# BALA independent source-loss leverage result v1.144

## Question

Does losing an occupied source that supplied a larger fraction of a surviving island population's pre-loss source access predict greater subsequent contraction?

The test was prospectively frozen before BALA3 outcomes were opened.

## Design

The Azores BALA arthropod monitoring system provides three ordered phases:

- BALA1: pre-loss source state;
- BALA1→BALA2: source-loss exposure;
- BALA2→BALA3: later contraction/persistence outcome.

The primary analysis retained taxa with at least two occupied BALA1 islands, exactly one lost source by BALA2 and at least one BALA2 survivor. The lost source itself was never scored as a target.

The pre-t2 gate passed with 20 exactly-one-loss taxa, 64 target rows, 53 distinct target-specific lost-access fractions E_i and 20 prefeature-estimable leave-one-taxon-out folds.

R2 included island fixed effects, source counts, surviving-source Euclidean geometry, diffuse source pressure, prior target occupancy and BALA3 pitfall effort. C added only E_i.

## Result

After the one permitted BALA3 read:

- eligible taxa: **20**;
- target rows: **64**;
- contractions: **20**;
- persistences: **44**;
- estimable taxon folds: **20**.

Primary:

- C−R2 = **+0.000674**;
- 95% taxon-bootstrap interval = **[−0.02130, +0.02558]**;
- **primary not supported**.

Secondary descriptive summaries:

- mean E_i among contractions = **0.466**;
- mean E_i among persistences = **0.287**;
- full-data standardized E_i coefficient = **+0.279**;
- event ΔN_eff versus contraction fraction Spearman rho = **−0.180**.

These secondary quantities were frozen as nonrescuing and do not overturn the failed heldout primary.

## Ecological meaning

The global mammal system showed that ultrarare occupied sources can differ strongly in spatial leverage and that actual adjacency can contain presence information.

BALA tests the stronger conservation implication: whether losing a high-leverage source predicts later contraction beyond source count, remaining-source geometry, island identity and survey effort.

It did not.

Therefore:

> **spatial source leverage is not yet validated as a general conservation-prioritization metric.**

A source island may be structurally distinctive in a static occurrence network without its loss having a generalizable downstream occupancy consequence.

## Claim boundary

Supported:

- the test is independent of the global mammal discovery system;
- exposure precedes the later endpoint;
- all confirmatory features and folds were frozen before BALA3 access;
- the primary is estimable and non-supportive.

Not supported:

- high-leverage source loss predicts greater subsequent contraction;
- source leverage identifies populations whose protection prevents extinction;
- graph paths are realized dispersal routes;
- the mammal cross-sectional leverage diagnostic transfers generally across taxa and systems.

No BALA rerun, threshold change, taxon subgroup search or secondary rescue is authorized.
