# A-Islands island-biogeography paper direction v0.1

## Working ecological claim

**Mainland isolation does not equal source isolation.**

Across Australian continental islands, classical island state variables explain most occurrence support under ordinary conditions. But at the most mainland-remote islands, focal-species occurrence is better organized by whether the island remains connected to the species' occupied insular source network.

The ecological contribution is a **source-pool handoff hypothesis**:

> Nearer and ordinarily connected islands are primarily described by mainland access, island area and direct source context. Under extreme mainland isolation, the relevant source context can shift toward continuity with occupied source islands inside the archipelago.

## Candidate title

**Mainland isolation does not equal source isolation: occupied insular source networks structure occurrence on remote continental islands**

Alternative:

**From mainland access to insular source networks: a source-pool handoff across remote islands**

## Why this is island ecology rather than a connectivity-method paper

The central objects are ecological:

- island area;
- mainland isolation;
- species range/source breadth;
- occupied source islands;
- direct versus multi-hop insular source continuity;
- remote-but-linked versus remote-and-unlinked island states.

The graph is only an operational representation of source-network continuity.

The paper does not claim a new universal connectivity metric.

## Core narrative

### 1. Classical island state dominates ordinary occurrence

Climate, island area, mainland distance and nearest focal-species source account for most of the held-out occurrence information.

This recovers the classical expectation that island area and isolation matter, while explicitly acknowledging the source pool.

### 2. Widespread species are source-saturated

Species occupying many islands have many possible source anchors.

Accordingly, adding species-conditioned topology is especially redundant for widespread species under ordinary island conditions.

This is a source-saturation result, not simply a statistical prevalence effect.

### 3. Extreme mainland isolation breaks the equivalence between geography and source access

At high mainland remoteness, the same mainland-isolation state can contain two biologically distinct island classes:

- remote-and-unlinked;
- remote-but-linked to occupied insular sources.

This is where the classical mainland-oriented description loses resolution.

### 4. Multi-hop insular continuity carries the strongest ecological signal

A focal island can be farther than the smallest graph radius from any occupied source while still belonging to that source component via intermediate islands.

The multi-hop state strongly differentiates occurrence-support patterns even after nearest-source distance is represented.

Thus the biologically meaningful object is not only source proximity; it is source-network continuity.

### 5. Effective source pool may shift with isolation context

The synthesis suggests a context-dependent source pool:

- ordinary islands: mainland/direct-source context dominates;
- extremely remote islands: occupied insular sources can become the relevant source context.

This is the source-pool handoff hypothesis.

## Main results to foreground

### Result A — source saturation

C−R3 adversity increases with occupied-island breadth:

- Spearman rho = +0.201;
- Pearson r = +0.422;
- >=61-island species: mean C−R3 = +0.0190; favourable fraction 26.1%.

Interpretation: broad distributions create many source anchors, making additional topology redundant under ordinary conditions.

### Result B — remoteness, not area, moderates redundancy

Breadth × mainland distance:

- beta = −0.00267;
- p = 7.3×10⁻4.

Breadth × island area:

- beta = +0.00098;
- p = 0.125.

Interpretation: the regime change is tied to mainland remoteness, not simply large versus small islands.

### Result C — source-network decoupling

All 15,225 rows with source-conditioned connectivity exceeding generic mainland stepping are in the frozen remote tail.

The characteristic state is:

- source-conditioned frequency = 1.0;
- generic mainland stepping = 0.75.

Interpretation: mainland access has broken at the smallest scale while the focal-species insular source network remains connected.

### Result D — reference gap follows source-network continuity

Remote-panel R3 calibration residual is larger under:

- excess source connectivity: beta +0.0726;
- continuous source-minus-generic connectivity: beta +0.0889;
- multi-hop source path: beta +0.0644.

Direct source within 25 km is weaker (p ~ 0.073).

Interpretation: path continuity is more informative than simple local source adjacency.

### Result E — multi-hop state

True-presence rows:

- multi-hop: mean C−R3 = −0.1042, favourable 77.8%;
- no multi-hop: mean +0.0810, favourable 35.5%.

Paired-species mean difference = −0.2064.

Interpretation: intermediate islands can preserve source-network continuity beyond direct source distance.

## Discussion structure

### A. Isolation is relational, not only geographic

An island has no single biologically sufficient isolation value.

Isolation depends on the focal species' occupied source configuration.

### B. Source pool is spatially dynamic

For remote islands, the effective source pool may be increasingly archipelago-internal rather than mainland-anchored.

### C. Stepping stones are species-conditioned

A physical intermediate island matters only if it contributes to a path linking the focal island to permitted occupied sources.

This differs from generic archipelago centrality.

### D. Range breadth changes the meaning of connectivity

Broadly distributed species are source-saturated in ordinary landscapes, but that redundancy can weaken under extreme remoteness.

### E. Historical versus contemporary interpretation remains unresolved

Because A-Islands are continental islands, the source-network pattern could reflect:

- contemporary inter-island dispersal;
- rescue/persistence;
- shared historical occupancy;
- correlated unmeasured environment.

A temporal/genetic independent test is required to discriminate these.

## Strongest defensible conclusion

> Across the A-Islands system, classical island state variables absorb most structural information overall, but extreme mainland isolation reveals a distinct species-conditioned source state: islands that remain connected to occupied insular sources show occurrence support not captured by area, mainland distance, nearest source, diffuse source pressure or generic archipelago stepping alone. This suggests that the effective source context of island occurrence can shift from mainland access toward archipelago-internal source-network continuity.

## What not to say

Do not write:

- "stepping stones cause colonization";
- "remote islands are rescued by neighbouring populations";
- "25 km is the dispersal scale";
- "network connectivity universally improves island occurrence models";
- "A-Islands proves the source-pool handoff mechanism."

Until independent confirmation, use:

- "consistent with";
- "marks";
- "distinguishes";
- "source-network state";
- "hypothesis";
- "occurrence support".
