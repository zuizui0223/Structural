## Original predictive question and frozen modeling recipe
**Q:** Given the same general forest recovery context, does **offered tree-host identity** improve prediction (A) of any observed adult beetle emergence and (B) of detected species composition conditional on emergence, and is the incremental value dependent on recovery stage?

**Independent holdout unit:** one original physical plot with all five offered host logs held out together; leave-one-**plot**-out (LOPO). One source study/landscape only, so no outside-country/biome transport inference.

**Baseline E0:** source `Category4` (four ordered categories modeled categorically), `History` as source categorical, plus original numeric `Elevation,Latitude,Longitude`; all feature encoding and numeric scaling learned only in each training fold. No nonresponse information chosen by output significance. All original eligible field plots retained; missing covariates cause STOP, never favorable-row deletion. **E1** = E0 plus five-level offered `Host` factor. **E2** = E1 plus `Host × Category4` factor interaction (only E1→E2 designated exploratory). No `WoodDensity` in E1/E2 because host and density are not separable. No adaptive lambda/model selection, extra spatial radius or source subset after results.

- **Y1 (primary if recovered-log zero opportunity gate passes):** observed `Indiv>0` per recovered log. L2 logistic regression `C=1.0`, sklearn `lbfgs`, `max_iter=2000` for E0,E1,E2; one binary log loss for every log, averaged equally within held-out plots and then plot-equal. A no-emergence observation means **no observed emergence**, not certified colonization failure. Report E0−E1 log-loss gain and E1−E2 only exploratory.
- **Y2 (secondary but mechanistically distinct):** for logs where positive emergence is recorded, detect each distinct `Morphospecies` (incidence not abundance-weighted) as 1. Convert each log's relative detection incidence profile to Hellinger vector (square root of incidence / sum of detected species), independently across logs; restrict to the source union of eligible morphospecies WITHOUT outcome-adaptive taxon trimming. Multivariate L2 ridge regression `alpha=10.0`, intercept, one-hot+scaled source E0/E1/E2, predicted nonnegative coordinates clipped at zero then L2-normalized; squared Euclidean Hellinger-vector loss, plot-equal across eligible positive logs. Predictive target remains *observed detected morphospecies*, not true ecological occupancy or biomass. Score E0−E1; E1−E2 exploratory. If zero predicted norm, use fold-train average response normalized (predefined fallback).
- If the source observation has only aggregate means without per-log presence opportunities, Y1 must not run. Y2 requires exact per-log linkage as above.

**Uncertainty:** for each endpoint/effect, independently store anonymous per-plot deltas; report plot-equal signed gain, number of plots improving/worsening, 4000 resampling-plot bootstrap 95% percentile CI with seed 20261122, and 9999 random plot sign flips two-sided against a symmetric-zero null with same seed. This is retrospective source-conditional uncertainty, not independent external replication; values of multiple endpoints, folds and permutes do NOT count as additional sites. Do not call p<.05 confirmatory. Exclude empty heldout-Y2 plots from Y2 averaging only (not from original Y1). Report plot-category counts and matched source design diagnostics without dumping original site or taxon IDs.

**Interpretation:** Only a demonstrated LOPO improvement for E1 relative to E0 supports *within-this-source incremental host-resource predictive information*. E2 would indicate within-source predictive host×stage modification. Neither demonstrates biological colonization, host-wood availability in the surrounding landscape, decay-stage continuity, spatial connectivity or a universal forest assembly mechanism. Entire original dataset is previously published; do not recycle its known ecology as new discovery. PREDICTS/NEON/Finland/Chiu/Carpathian/BALA/GEB frozen outcomes are untouched.
