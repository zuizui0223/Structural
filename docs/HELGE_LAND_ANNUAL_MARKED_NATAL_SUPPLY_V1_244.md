# v1.244 — Does annual natal-source supply improve the next-year immigration route forecast?

The source co-failure hypothesis is the mechanism of interest, but observed immigration shares do not establish real source failure. The prior v1.239–v1.241 analyses used pooled, already-published natal sparrow migration counts. v1.241's pooled pairwise prediction gain could be eliminated by excluding Sleneset, and original inter-island geographic distances remain unavailable via publisher DOI (v1.243 API HTTP401 and website HTTP403).

This is a deliberately NARROW retrospective test of temporal source activity: Count the number of uniquely nest-marked birds on each of the eleven islands in birth year t, regardless of whether they are seen again next year. These counts are known at t, and are **not** true natal production or adult source viability (marking effort varies). Historical 1994-2013 marks plus documented t+1 emigrant observations estimate island-specific "observed migrant yield per marked nestling", with fixed (M+0.5)/(N+1) smoothing. Routing probabilities train entirely on 1994-2013 source/resight events using the four previously frozen route models P0, H, R2 and C2 (tau 10; historical-only habitat beta). The 2014 cohort is excluded. Later birth years 2015-2021 predict next-year observed receiving island distributions in 2016-2022.

**Primary score pre-frozen before this new annual source join** is dynamic minus static heldout destination log loss under R2. Static source weights are the 20-year mean historical marked nestlings per island times training observed migrant yield; dynamic weights replace ONLY historical source-volume estimates with that birth year's marked nestling count, leaving source yields and route model unchanged. Compare the exact same 173 documented later migrants, conditional on an emigrant's being observed. Secondary route models P0, H, C2 are fixed checks, all reported regardless of sign. All seven test birth years and all 11 source-marking counts are included and must reconcile exact original v1.231 aggregated cohort anchors 9868/259 historical, 664/28 boundary, 4484/173 later. No future resighting label enters training state, and the 2026 author model's full-series-adjusted N_corr is intentionally not used as a lagged prospective covariate.

Scientific interpretation: a negative primary score would only show that time-varying *marked nestling supply* helps predict observed next-year immigrant destinations beyond a static historically estimated supply; it could be generated by marking effort or known life-history patterns already investigated in Ranke et al 2021. A nonnegative result is no positive support for this time-activity representation. No true source loss, donor demographic independence, recipient rescue, actual 0→1 island recolonization, or independent confirmatory observation is demonstrated. Original GEB scientific HOLD and eBird prohibition remain.
