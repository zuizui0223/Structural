# v1.247 — Published article describes 60 five-patch landscapes, but author raw and derived files include 62

The pre-outcome protocol v1.246 expected 3 food webs x 4 spatial-source configurations x 5 independent landscapes =60, with 15 one-peripheral-source replicates, matching Gawecka et al.'s 2025 published methods. The original source-fingerprinted CSV itself has 693 observations from 77 landscape IDs with nine visits each (15 five-source controls + 62 four-config experimental landscapes). The two extra biological landscapes are *both* in the most complex BRBR_LIER_DIRA treatment: 1C/replica6 and 1P/replica6 (9 visits each). The original author derived recovery output also has 62 non-control landscape replicates, so these are not simple duplicated source rows.

The response-labeled data were already read when this discrepancy was found. We therefore **preserve v1.246's fail-closed 60-landscape gate** and create a separate v1.247 **postexposure** two-denominator audit with no favorable-effect selection:
- **Paper-described primary** includes ONLY replica1–5 in all cells (exact 60 landscapes, 15 focal 1P, 150 initially empty patches, 45 distal source-distance-2 series).
- **All-original sensitivity** reports 62 source landscapes, including BOTH sixth replicates, giving 16 focal 1P, 158 originally empty patch series, and 48 source-distance-2 patch series.
- Both use the identical original v1.246 first-observed-positive classification and right-censored no-detection handling, measured from actual author timestamps. The complete source and the two authors' files are Git-source-locked; no source values are ever silently replaced.

A first positive distal patch preceding the first sampled positive in the obligatory central stepping stone is not evidence that aphids violated the star's migration path. It is evidence that inferring transit-state occupancy solely from intermittent discrete sampling can be misleading. The original authors already reported that number, location and foodweb complexity affect empty-patch recovery; this particular timing assay is a bounded *retrospective* extension rather than independent confirmation.
