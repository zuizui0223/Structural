Do not pool these raw values, regardless of the simpler top-level BExIS `Unit=cubic meter` declaration; do not add either to `Vharv` (stump-derived harvested wood, m³/ha).** The original *source-item measurement* is not the same as BE31123 experimental log supply: 2012 existing ambient forest deadwood vs 13 deliberately offered hostwood categories over 2010–2017, with time lag and possible forest-sampling area corrections.

### Version and rights provenance closed

A discovered publisher-source API versioning mistake was fixed **before any biological analysis**. The official BEXIS2 data endpoint `/api/data/{id}` returns latest, whereas `/api/data/{id}/tag/1` explicitly requests the first public tagged release. [**Actual source version CI #43708115836 SUCCESS**](https://github.com/zuizui0223/Structural/actions/runs/43708115836) retrieved both 31123 and 24546 `tag/1` and found **byte-for-byte SHA256 equality** to the previously downloaded latest files. Both tag1 original sources reproduce **30/30 exact plotID overlap**. Source 24546 `tag/1` reports internal `version=2`/`versionId=4191`, illustrating why a tagged publication is **not automatically an internal version1**. [Separate reproducible result, original hashes and full CI](FOREST_BELONGDEAD_BEXIS_TAG1_VS_LATEST_ORIGINAL_PLOT_JOIN_ACTUAL_RESULT_20261115.md).
