# 林冠甲虫の三次元ニッチ：距離換算と実測トラップ高度の判定（2026-11-08）

## 完了した作業と結論

**先行する肯定的実測を保持**：タイ2森林・18物理採集地点・2採集期の原GBIF甲虫1,622個体（SLAM 144瓶Event）では、同一地点・採集期で林冠899個体、下層723個体。サイト・2季節を保持した林冠−下層差平均+4.889個体／地点・採集期、条件付き地点内符号反転p=0.00439、2森林内層化地点bootstrap 95% CI +2.306〜+7.611。科組成の垂直Bray–Curtis平均0.54778。同じ層の異なる地点間は0.51419。ただしこのタイの甲虫データは原著Punthuwat et al. (2024, DOI 10.1002/inc3.76)が既に林冠・下層・季節・beta turnoverを解析している。独立の新しい生物学的発見と呼ばない。

### H2：上下の科組成差に相当する水平距離は推定できるか

同一原本 SHA256 `1565cf6d7f1e7289e28756367e3d137f64723dc1fa0a06d799f6abdb523e1339` にて、2森林×2採集期の各9地点を用い、同じ層の別地点ペアの距離–科組成非類似度を4等頻度ビンで記述。横軸は地表面上の**水平距離**であり、林冠の**垂直高度**やトラップ間の水平ずれと混同しない。

| 判定 | 原データの結果 |
|---|---|
| 水平距離の観測範囲 | 104.82〜482.57 m（中央値237.22 m） |
| 上下の罠の水平位置ずれ最大 | 42.02 m |
| 同層近距離（42m以下）の直接比較 | **0** |
| 距離四分位の平均βが非単調 | **3/4**森林×採集期 |
| 残る1条件 | β変動幅0.0375、事前固定の最低変動幅0.05未満 |
| 水平距離の条件付き換算ゲート成功 | **0/4** |

**結論：林冠・下層の非類似度を、現データで水平X mへ換算することは不可能。** 外挿値は出さない。これは「垂直分化がない」「水平距離減衰が普遍的にない」を意味しない。観測距離の支持域がずれ、4条件で単純単調距離モデルが成立しないため、定量化不能と判定した。実験設計では少なくとも0–100 mの同層水平対照、実際の垂直距離、分類精度と標本数を統一した多森林反復が必要。

コード：`analysis/forest_macro_global/thai_beetle_distance_decay_gate.py`。テストと原本監査 [CI #42440065400](https://github.com/zuizui0223/Structural/actions/runs/42440065400) SUCCESS。

### H1の前段：林冠トラップの実高度は原公開Eventにあった

原著は林冠トラップ約12–30m、下層2m、両層でHOBOによる毎時温度・照度（lux）を約1か月測定した。今回原GBIF Eventの`dynamicProperties`文字列 `trap height in meters:数値`を**288 Eventすべて**について正しく抽出した（初回ゼロは正規表現の読み取り不具合で、原本欠測ではない）。

| 原本のトラップ高度 | 数値 |
|---|---:|
| 甲虫SLAMの林冠Event | 72行、高度11.3〜26.4m、中央値18.85m |
| 甲虫SLAMの下層Event | 72行、全て2.0m |
| 同一18地点で2採集期の林冠高度の差（絶対値） | 中央値1.55m、最大4.10m |
| 高度変化2m超／4m超の地点 | 7／2地点 |

同じ地点でも一部で実際の設置高度が変化するため、**地点ごとに固定の林冠高度という前提を採用した最初のモデルはSCIENTIFIC STOP**。4m超の2地点を都合よく除外しない。原Eventのみで行った安定性監査 [CI #42440897606](https://github.com/zuizui0223/Structural/actions/runs/42440897606) は成功。

### 実際の採集期別高度×甲虫捕獲比の探索的関連

18地点×2採集期＝36の林冠−下層対応単位を保ち、各採集期の実トラップ高度を説明変数にする**事後的な探索モデル**に切り替えた。応答は両層のSLAM個体数による `log((canopy+0.5)/(understorey+0.5))`。森林×採集期の切片を調整し、物理地点の二季節の高度系列ごと森林内で9,999回置換、同じ物理地点系列を維持して森林内5,000回再標本化。

| 指標 | 数値 |
|---|---:|
| 高度10m上昇当たりの対数捕獲比の傾き | +0.11568 |
| 比率尺度の記述的倍率 | 1.123倍／10m |
| 2森林の地点系列置換による両側p | **0.5755** |
| 森林内地点系列bootstrap 95% CI（対数傾き／10m） | **−0.3102〜+0.5552** |
| 森林×採集期別傾きの符号 | 3正／1負 |
| 物理地点leave-one-outの符号維持 | 17/18 |

**このデータでは、林冠が高い地点ほど甲虫の林冠捕獲割合が一貫して増えるという関係は支持されない**。不確実な区間は負から正まで含み、高さの効果がゼロと確証されたわけでもない。林冠側に甲虫が相対的に多かった**肯定結果は維持**される。高さは林冠構造の一部であって、樹種・葉量・腐朽木・微気候・捕獲率を代表する単一因子ではない。

コード：`analysis/forest_macro_global/thai_beetle_timevarying_height_response.py`。[CI #42441114705](https://github.com/zuizui0223/Structural/actions/runs/42441114705) SUCCESS。

## 科学的な主質問の更新（まだ未検証）

**森林の垂直ニッチ分化は、温暖化に対する逃避経路を増やすのか、それとも資源への専門化によって上下移動を制限するのか。**

区別するために必要なもの：

- 同じ種・モルフォ種の林冠/下層の繰り返し観測。公開GBIFの甲虫1,073出現行は属・科・亜科レベルが混ざり、個体単位での種同定・絶対密度は保証されない。著者原論文の437 Coleoptera speciesと、この公開GBIF原本のspecies同定数は同義ではない。
- 同じ地点のHOBO原時系列（1時間刻み温度・照度）。原論文に観測と日中の林冠高温化、夜間の収束が報告されているが、**GBIF Event原本には時系列が同梱されていない**。原著の既報効果を新解析の発見にしない。
- 林冠と下層の寄主樹種・葉量・デトリタス・枯死木・食物源、およびトラップ捕獲率・採集高度の違い。温度差があっても捕獲が変化したことは**同一個体の垂直移動**を意味しない。
- 少なくとも異なる森林タイプ・地域の元データで事前固定した同じ応答と推定単位を再現。現在の独立森林はn=2。森林パッチ間の供給源連結性や島嶼の長期人口動態も別endpoint。

**現時点で成り立つ確実な理解**：垂直的な捕獲差と群集差は実測で存在。上下の差を水平距離に変換できず、単純なトラップ高度だけでは林冠捕獲優位の強さを十分説明できない。次に問うべきは、**温度・樹種・栄養資源のどの組合せが垂直ニッチを維持し、気候変化への逃避可能性を制限するか**である。これは仮説であって、今回検証済みの因果結論ではない。
