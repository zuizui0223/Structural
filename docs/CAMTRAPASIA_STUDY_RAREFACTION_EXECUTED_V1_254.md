# Executed camera study-ID rarefaction v1.254: actual sources but not ecological occupancy

The fixed post-outcome protocol, GitHub Action run 38008595850, used 74 Java/Sumatra studies, 38 original shared mammal binomials and source wild-positive photo-records. An exact finite-population source-study rarefaction on only pre-2017 camera campaigns compared Java's 18 historical camera studies (59,418 trap-nights) with 18 uniformly sampled studies from Sumatra's 49 historical campaigns (97,798 trap-nights total). A study-count-standardized Sumatra random subset averages 35,925.8 trap-nights, not the same effort as Java.

At 18 study IDs, the Java actual observed matching wild mammal positive taxa count was **13**, versus Sumatra exact expected **15.34585**, finite set draw 5th/median/95th **[14,15,17]** across 20,000 seeded subsets. The expected number of Java-positive taxa also photo-positive in rarefied Sumatra samples was **8.36734**. Sampled detected-name Jaccard 5/50/95 percentiles were **0.381/0.421/0.474**. Conditional rarity/discovery variation is NOT a population confidence interval. It does not rule out source design, habitat or per-survey effort differences as explanations. Baseline climate/ecological comparators were not matched.

A secondary *temporally confounded* full-year comparison standardized to Java's 25 surveys estimated 15.87855 Sumatra expected detected taxa versus 15 Java; it also includes four Java camera studies spanning 2017 and three studies beginning after 2017, while all Sumatra field campaigns ended by 2015. Source publication in 2024 cannot be used to claim a temporally prospective comparison for Sumatra.

Interpretation: the simple difference in numbers of surveyed **study IDs** does not fully account for the documented positive-record richness difference under uniform study-ID selection. This is not an estimate of true island richness, guaranteed native population persistence, colonization, dispersal, source-sink role or original mapped-label GEB predictive skill. Java and Sumatra occupy one original heldout geographic block. Source camera rows had been opened before the posthoc rarefaction question. The original 529 mammal IUCN heldout response and GEB predictions were not consulted. GEB scientific HOLD continues.
