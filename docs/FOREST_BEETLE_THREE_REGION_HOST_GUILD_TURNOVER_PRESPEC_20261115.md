# Independent three-country forest saproxylic beetle source: does taxonomic replacement reorganize host-tree channels? (2026-11-15, exploratory pre-result specification)

## Main question and source identity
The existing PREDICTS result (+0.0942 altered-vs-reference relative taxon replacement across 39 original studies) is positive, whereas one prespecified NEON static canopy-height contrast (+0.0349/10m, p=0.1759) was not supported. Neither yields a functional beetle host-channel endpoint. This **new, separately published** original source permits a bounded independent descriptive test: when recorded saproxylic beetle species change among forest sampling units, does their *host-tree affiliation distribution* diverge beyond what species composition, richness and the source pool alone predict?

Data: Burner et al., public Zenodo **10.5281/zenodo.5950610**, version v1 (2022-02-14), a species×sampling-column abundance table plus traits per **Finland, Germany, Norway**. The separate 2021 JBI paper DOI 10.1111/jbi.14272 and 2022 Biological Conservation 10.1016/j.biocon.2022.109491 already studied trait niches, co-occurrence and the contribution of rare species to functional richness/specialization/originality. **Claim only a retrospective original-data secondary analysis of a different target, never a new independent field study or new globally novel phenomenon.** Country is only a source reporting stratum; dates/protocol/field-site independence must be audited before interpreting sampling columns as physical forests. No canopy height, microclimate, local tree abundance, forestry manipulation or explicit movement network exists in this Zenodo bundle; the planned analysis cannot identify those mechanisms.

## Frozen source gate before biological endpoint
1. Download only six manifest-pinned original CSV, check each MD5, verify one species key column, unique source species names and unique sampling columns within country. Count raw file species rows and sample columns; count apparent year-prefix strings but do **not** claim unique forests. Source columns are allowed to represent heterogeneous historical years and sampling intensities. Missing input, schema mismatch, nonnumeric/negative detected counts or source trait categories outside documented `Host_tree` values trigger explicit scientific STOP, not imputation.
2. Original trait `Host_tree` categories exactly **broadl / conifer / both**. `both` is a **third generalist category**, not duplicated into two forest strata. Missing/NA trait scores are excluded with denominator published. Source taxon names must join **exactly** to one same-country traits row, no post-result taxon harmonization or genus-level relabel.
3. Use incidence `source recorded count > 0` per named beetle species×original sampling column, not abundance-weighted biomass, species richness of all insects, tree density, host-tree resource biomass, or species true absence. A column is eligible if `>=5` source-detected species have an observed Host_tree code AND Host_tree-coded detections/`all` species detections `>=0.60`; a country requires `>=20` eligible source sampling columns and `>=30` detected and host-coded species. If any country fails, record source gate and **no pooled test**, never lower it after inspecting the result.
4. Each source country contributes exactly one equal weight. Country is **not** 1 physical forest or 1 biome replicate. Within-country site pairs and repeated years are explicitly dependent; no naive pair-level standard errors/p-values.

## One planned biological endpoint (two-sided)
For each eligible sample column, `Host_tree` source-detected species incidence proportions across three mutually exclusive categories yield a 3-vector `p`. For every pair of eligible source sampling columns **within the same original country**, calculate **square-root Jensen–Shannon distance** `sqrt(JS(p_i,p_j) / log(2))` in [0,1]. With species presence held fixed, the country statistic `F_r` is the unweighted mean over valid within-country sample-column pairs of this **host-affiliation compositional distance**. Separately report species-rank Simpson beta `beta_sim=min(b,c)/(a+min(b,c))` for taxonomic turnover on **the same Host_tree-known species pool**, but do not subtract raw beta values from JSD (different metrics).

**Primary conditional null:** within each country independently **permute the 3-category Host_tree labels across the source species actually detected in eligible columns**, holding original species-by-column occupancy, sample-column richness/effort, original site pair structure and country-specific proportions of affiliation categories fixed. There is *no* pair-level shuffle and no post-outcome optimizing subsets. Use exactly **2,999 country-wise simultaneous permutations**, deterministic seed `20261115`. Per-country `F_r` null mean is `E_r`; one combined estimand `D=(1/3)sum_r(F_r-E_r)`. The null draws are `T_b=(1/3)sum_r F_{r,b}` centered by their mean; two-sided `p=(1+count(|T_b-mean(T_b)|>=|T_obs-mean(T_b)|))/(3000)`. Report *both* directions, country-level observed and null mean deviations, 2.5/97.5% **conditional null reference interval** (not a sampling CI), full sample attrition, original species/columns, raw observed species beta, and counts of country-wise signs. No additional wing/decay/feeding axes and no site filtering by effect sign.

### Interpretation
- **D<0** with small conditional-null p: detected host-tree-use channels vary **less** across these sampled assemblages than expected from randomized affiliations (functional buffering/redundancy **relative to this narrow conditional null**), not species persistence, stability through time, source rescue or ecosystem function measurement.
- **D>0** with small p: detected host guilds differ **more** than randomized affiliations (functional sorting **relative to this narrow null**), not identified causal tree-host availability or forest structural filtering.
- Neither/small-n: source does not support either deviation. Conditioning on country species pool does not remove spatial/detection/field-year confounding. Species-specific occupancy and trait-affiliation correlations can arise from sampling or habitat; no geographic location or source host-tree inventories were provided here.
- PREDICTS taxon replacement and NEON canopy structure differ in exposure, biology, period and methods, **not a pooled meta-effect**. This supplementary analysis does not replace original manuscript primary endpoints or rescue failed NEON effects.
