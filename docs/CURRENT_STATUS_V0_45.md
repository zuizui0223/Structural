# Structural current status v0.45

## Current scientific state

Structural now has **zero active empirical candidates** and **zero confirmatory-eligible systems**.

The prospective Indo-Pacific atoll native-plant test is closed.

Its corrected burned pilot opened under the frozen v0.31b/v0.42b design and immediately encountered a response code `U` outside the frozen plant endpoint domain `N/I`.

Because pilot response access had already started, that protocol version is consumed and cannot be rerun.

## What was learned

The atoll system did **not** test the ecological source-pool-handoff direction.

No effect size was estimated.
No predictive score was calculated.
v0.32 and v0.42 were not completed.

Confirmatory species and presence values remained sealed.

Therefore the atoll outcome is neither favourable nor adverse evidence for source-pool handoff.

It is a distinct empirical failure mode:

**endpoint value-domain mismatch**.

## Failure-mode separation

Structural now has three empirically observed pre-effect bottlenecks:

1. **endpoint/class collapse** — PNW and RMNP;
2. **response-quality attrition** — LandFrag;
3. **categorical endpoint-domain mismatch after pilot access** — Indo-Pacific atoll plants.

All three occur before a connectivity effect can be interpreted.

## Island-biogeography implication

The A-Islands source-pool-handoff hypothesis remains a hypothesis generated from frozen A-Islands exploratory results.

The atoll dataset does not confirm or refute it.

Its value was instead to show that a carefully response-sealed island system can still fail before ecological inference if the actual response state space is broader than the prospectively frozen codebook.

## Next valid event

Do not repair or rerun the atoll dataset.

The next valid confirmatory opportunity is a **different, independently available island system** that can enter response-sealed with:

- a complete or explicitly bounded categorical response domain;
- frozen response-independent geography;
- v0.31 partition/endpoint gates;
- v0.42 response-quality rules;
- no response-based candidate selection.

Until such a system arrives, the live confirmatory queue stays empty.
