## ONE frozen original ecological primary estimand
Do measured **local** log-and-z deadwood amount add site-community host-tree-guild composition prediction over climate, landscape continuity, forest age, effort and coarse spatial location, when predicting **unseen geographic grid blocks**? Positive incremental prediction is the hypothesis. This is not a directed test for individual broadleaf or conifer guild trends, since VD10 is *total* deadwood amount, not guild-specific host availability.

- Site response, once per 142 author physical sites: use original `Finland_sites.species.csv` **count>0** incidence and the same exact source `Finland_traits.csv` `Host_tree` categories `broadl`, `conifer`, `both`. Original source-event eligibility **>=5 known guild species and >=60% guild trait coverage**, and the original 153/153 qualified event cohort must reproduce; otherwise scientific STOP. Known guild species shared within Finland, missing traits not imputed. `both` is a third class. For site i, `p_i` = relative count of distinct detected Host_tree-known source species among 3 guilds; `Y_i=sqrt(p_i)` Hellinger embedding (3-vector, unit Euclidean norm). No source abundances, species richness weighting or biomass.
- Environment full source 2023 142 author Site/Year rows, **exact 2022 source-year match**. Before biological read, require exactly 142 joined 2022 source event IDs and 142 unique author sites. One calendar year/physical forest. Verify every preselected predictor finite; no imputation, no favorable exclusion.
- **Baseline** predictors (9): source author `agedomin`, `OldFor_1km`, `MeanTemp`, `TotalPrecip`, `globRad_WHm2`, `log_Nr_traps`, `lat_WGS84`, `lon_WGS84`, and `Year`. No `climID` dummy terms (it can have > 50 levels); use geography-block holdout and source climate fields instead. **Extended** adds ONE predictor `VD10` only. The published 2023 source z scores are used directly, NOT log transformed again. For each training fold, **all** predictors are centered/scaled using training means/sample SD; constant source columns are scale=1 and left 0. Test values use only training scalers, avoiding leakage.
- Nonlinear site guild composition predictions are obtained from deterministic multivariate ridge regression on `Y=sqrt(p)`, **ridge penalty λ=10 fixed a priori** on predictors, intercept unpenalized. Predicted 3-vector `q` is truncated to nonnegative and Euclidean-normalized so that its 3 squared entries sum 1 (predicted guild proportions). The loss per site is **squared Hellinger distance** `H2_i = 0.5*sum((Y_i-q_i)^2)` in [0,1].
- Geographic holdouts: fixed **1° latitude × 2° longitude** grid by `floor(lat_WGS84)` and `floor(lon_WGS84/2)` (roughly 100km-scale in Finland). For each occupied grid cell, train on all OTHER cells, predict every held-out source site once. Minimum 8 occupied cells, >=100 eligible original sites and >=80 training sites in each fold, otherwise explicit scientific STOP; original sample selection not altered. This approximates withheld geography; sites near neighboring grid boundaries may still be close, so no true outside-biome claim.
- Primary estimand **Δ_H2** = **unweighted mean across geographic grid cells** of (baseline mean heldout Hellinger² error − plus-VD10 heldout error) **at source site equal weight within each cell**. Positive = adding measured deadwood improves geographically heldout guild-composition prediction. Also report pooled per-site error, number of positive/negative/zero blocks, actual number of forests/grid cells and original source years. Do **not** call grid cells independent field experiments.
- Uncertainty: **4000 bootstrap replicates resampling the spatial cells as units** (seed `20261115`), percentile 95% CI for cell-equal Δ. Conditional descriptive two-sided signed-block randomization p via 9,999 independent sign flips of **cell-wise mean error contrasts** (seed `20261116`); it requires sign exchangeability and is not a general spatial causal null. Both p and CI must be reported whether the direction is favorable or not. Predeclared *exploratory support* only if Δ>0 AND 95% spatial-block bootstrap CI excludes 0 AND signed-block p<0.05; otherwise not supported. Also report the full-model fitted 3 guild component coefficients for VD10 as **descriptive only**, never test guild individually or promote best-sign component.

## Interpretation and prior work firewall
A positive Δ would mean *one predeclared local deadwood z-score improves host-affiliation guild composition prediction conditional on other original source features in **this same historical Finnish field cohort***. It would NOT establish actual local conifer/broadleaf resource supply, individual niche adaptation, forest management treatment, vertical canopy refuge, biodiversity biomass or cause-and-effect. Negative/inconclusive Δ is an informative non-support of **this incremental prediction**, not "deadwood unimportant for saproxylic beetles".
