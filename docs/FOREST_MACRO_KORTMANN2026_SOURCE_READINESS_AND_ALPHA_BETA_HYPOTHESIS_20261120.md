## What is genuinely testable if a field-method gate passes

The first prospectively distinct **ecological question** is not the authors' alpha diversity increase, nor BETA-FOR99's G-W difference. Instead:

> Within the SAME matched forest triplet, is taxonomic replacement relative to the undisturbed patch larger after post-disturbance clearing than after natural disturbance with deadwood retained, and does the result depend on forest type?

Candidate source-independent estimand, before source biological rows:
`D_site = beta_sim(undisturbed, cleared) - beta_sim(undisturbed, disturbed_unmanaged)`.
A positive value means detected-OTU replacement is larger under cleared state than unmanaged disturbance. This **does NOT** prove clearing caused the contrast (triplets are naturally selected, not a new randomized logging intervention), and does not say within-state spatial beta rose or fell, as every site has only one patch per state.

**Prebiology STOP conditions:** require original `site × state × sampling period` key and true exposure/attrition frame, site state labels, actual dates/forest types, common coverage/effort method and site blocks. Missing nominal sample opportunities must not be called biological zeros. Source method and geographically meaningful held-out units must be frozen before any OTU response. Choose one coverage-aware binary taxon operator and primary uncertainty before opening the source OTU data; because four forest types are nested in Bavaria, they are not four independent global biomes. This will be a separate observational source-level test, **NOT** a strict replication or meta-averaging partner of BETA-FOR99.
