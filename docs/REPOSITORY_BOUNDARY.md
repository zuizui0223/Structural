# Repository boundary

This repository is the canonical home of the Structural paper.

It contains only the Structural manuscript, frozen A-Islands/Tanzania evidence required by that manuscript, manuscript-facing figure/table assets, and reproducibility/release infrastructure.

It must not absorb the EOG-WF three-endpoint programme. Conversely, future EOG-WF development must not use this repository's A-Islands or Tanzania systems as extra EOG-WF replications.

The conceptual connection to EGWE is a shared residual-information/state-adequacy principle only. No EGWE result changes the Structural empirical denominator.
