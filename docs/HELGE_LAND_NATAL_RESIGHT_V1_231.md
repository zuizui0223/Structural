# Helgeland v1.231 — documented next-year natal transfers, not demographic rescue

Source data are already published in 2026 and overlap Ranke et al. (2021), doi:10.1111/1365-2656.13580. The code reports only birds individually observed as **nest** on exactly one natal island/year, and recorded as **capt** or **obs** on exactly one focal island in the following calendar year. A different destination is a documented natal disperser recruited into another study island; unchanged island is a documented resident recruit. Missing observation is not death; a bird lacking a nest-stage location has unknown natal origin, irrespective of its first adult appearance. No unobserved emigrants, capture probabilities or demographic source contribution are imputed.

Freeze historical natal cohorts 1994–2013, transition birth cohort 2014 separately, later cohorts 2015–2021 (follow-up in 2016–2022). Every one of the original eleven island IDs is represented in each cohort's source table even if export count is zero. Count each marked individual no more than once for each precommitted next-year endpoint. Individuals with ambiguous natal islands or multiple observed adult destination islands at the same next-year survey are excluded with counts.

The prospective ecological question is whether a source island **exports successful recruits**, not merely many birds: donor effectiveness should ultimately account for initial natal production, immigrant detection, later survival and independent offspring production. The present positive resighting is **not** sufficient to claim recipient-island rescue, successful breeding, local colonization or source/sink causal ranking. One archipelago, one long-term study, and study-year overlap with already published dispersal work do not yield a new independent confirmatory experiment.

After this bounded post-outcome descriptive audit, do not select whichever island or cohort looks favorable to generate a significance claim. The original GEB scientific HOLD and all burned-pilot gates remain unchanged.
