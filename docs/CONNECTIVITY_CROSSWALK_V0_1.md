## What this changes

The next development no longer asks only:

> Does connectivity matter?

It asks:

> **Which representation level and biological operator carries residual information for which endpoint after the current state/reference is supplied?**

That distinction gives a development ladder:

1. **geometry adequacy** — does structural configuration add information beyond local state and source proximity?
2. **process adequacy** — does a declared process model add information beyond geometry and the current state?
3. **realized-connection adequacy** — does observed movement/gene/pollen/recolonisation add information beyond the process model?
4. **operator portability** — does an earned result transport to another process operator?
5. **origin residual** — after the best current state and typed connectivity are supplied, does isolation/fragmentation history still matter?

Each step can stop. A failure at one level is informative; it is not a reason to tune until a positive result appears.

## Current frozen-paper interpretation

A-Islands EOG remains a geometry-level result. Its original positive conditional ordering does not identify a movement operator, and its adverse C - R3 predictive result does not show that all biological connectivity is irrelevant.

Tanzania current flow is stronger than pure geometry because it uses a resistance-based process model, but it still is not observed animal movement or a calibrated demographic dispersal probability.

Therefore the frozen Structural paper sits mainly at levels 1–2 of this ladder. The post-closure programme asks how to move to levels 3–5 prospectively without relabelling old results.

## EGWE connection

EGWE's failed transport of one connectivity-labelled result across allele mixing, whole-individual movement and pollen flow supplies the operator-identification warning that Structural lacked.

Structural supplies the complementary reference-conditioning rule: even a biologically plausible operator must show incremental held-out value beyond the state already supplied.

Together:

> **A connectivity coordinate must earn both adequacy and operator identity before it can be treated as a future-relevant state variable.**
