# 森林マクロ生態学：主解析の組み直し

2026-11-06。ユーザーから「文献の個別データを再解析するだけでマクロ解析になっていない」と指摘を受け、研究の主線と完了条件を修正する。

## 現在の事実と変更

PR #469のBALA/SLAM分析は、アゾレスの既存調査区画に環境変数を接続した**地域事例・方法検証**である。採集を1,911件に増やしても、独立した地域・気候帯が増えたわけではない。既存の肯定結果と不支持結果は保存するが、これを全球／森林帯を越える森林マクロ生態学の完成とは呼ばない。BALA投稿ファイルの更新、同じ地域の追加有意差探索、メール作成は現在の主目標ではない。

公開された他者の原観測を使うこと自体は妨げではない。ただし、新しい大規模データベースに差し替えるだけでも主線は直らない。森林生態学上の問い、比較母集団、環境指標、外部評価を独自に揃え、複数地域・森林帯に通じる関係を検証する。

## 独自の主質問（検証前の仮説）

**森林量が同程度でも、生物群集が異なるのは、森林内部構造がその地域の気候・立地条件に対してどの程度異なるからか。森林の連続性はこの関係を変えるか。**

比較例として、同じ樹冠高の森林であっても、低い樹冠が自然な乾燥・寒冷条件の森林と、より高い樹冠を持つ近傍参照森林が存在する温暖湿潤条件の森林を同じ質とみなす必要はない。ただし「低い＝劣化」「高い＝良好」と最初から決めない。

主候補は、樹冠高・高さの空間的不均一性・測定可能な林冠内部構造を、気候・土壌・地形が似た、独立に選定した低攪乱森林の分布と比較する方法。構造偏差は生物応答を見る前に定義し、単純な林冠高より未学習地域の群集構成をよく説明するかを検証する。単に新しい指数を命名しただけでは新規性としない。

先行研究では森林構造の気候依存性、全球の樹冠高、GEDIによる広域の構造複雑性は既に扱われている。したがって、その地図をそのまま再描画したり気候との相関を再現したりすることを新規発見としない。

## 比較の組み方

1. **環境の母集団から設計する。** 全球の森林景観を気候帯・生物地理地域・連続性で層化する。既存論文の対象島だけで母集団を定めない。全球を目標にするが、実際の観測支持が足りない森林帯へ結論を外挿しない。
2. **環境と生物の観測単位を混同しない。** 衛星画素・森林景観セルは説明側。応答は元の調査地点とその調査面積・採集努力・期間である。百万画素を百万の生物群集反復と数えない。広域景観グリッドと局所プロットの対応尺度は、座標精度・調査面積・地図解像度の監査で決める。
3. **種数を唯一の主応答にしない。** まず同じ調査設計内で、参照森林に対する種組成の保持／変化と局所種数の相違を扱う。異なる大陸の種名を一つに並べて非共有種の多さを森林劣化としない。森林専門性・分布域サイズは別の信頼できる種情報が整った分類群で追加する。アゾレスの固有／在来／外来区分を全世界に流用しない。
4. **共通の環境指標を原座標・原調査年へ結ぶ。** 森林被覆、断片化・林縁、樹冠高と構造、気候・水分、土壌・地形、森林攪乱履歴を出典年・精度付きで接続する。2020年林冠高を1990年代の観測と同時点とみなさない。樹高地図の表面ばらつきは、林冠内部の鉛直複雑性そのものではない。
5. **地域外への予測で判定する。** 地点のランダム分割だけでなく、研究・地域・気候帯のまとまりを学習から外す。基準モデル（気候＋森林量）に絶対構造、条件付き構造偏差、景観との交互作用を加え、未学習地域への改善と限界を報告する。研究ごとの方法差と分類群の違いを保持し、局所の係数を単純にプールしない。

## データの位置づけ

| 資料 | 使う役割 | 現在確認したこと／未確認事項 |
|---|---|---|
| 全球森林被覆・攪乱履歴 | 森林母集団、景観量、採集時期との整合 | BALAのWorldCover接続は地域パイロット。全球母集団はまだ未構築 |
| 全球2020年10 m樹冠高（Lang et al.） | 絶対構造と景観内の高さ分布 | 公開原著と製品の存在を確認。全観測地点への抽出は未実行 |
| GEDI由来構造指標（2024研究等） | 実測支持がある地域で林冠構造を評価 | 観測範囲・品質・年代・空間代表性を確認する必要。全球全画素の実測ではない |
| PREDICTSの公開地点×分類群観測 | 広域の群集応答候補。原著の結論やBII予測地図を応答として転用しない | 公開2016/2022リリースの存在を確認。公開全データの35,736地点という報告は森林解析適格数ではない。森林部分の件数、年、分類群、方法は未取得・未選定 |
| NEON等の統一モニタリング | 原年・方法を揃えてリモートセンシングとの接続を点検する候補 | 米国の調査系であり、それだけを全球再現とは呼ばない。使用データ・森林サイト数は未選定 |
| BALA・SLAM | 地表／樹上植生、検出、稀釈、固有性の扱いを検証する地域事例 | 既存結果は保全。全球主解析の新しい独立地域として重複追加しない |

PREDICTSは大規模データ候補に過ぎず、これだけを再解析するという設計には戻さない。生物観測のない森林格子は「種数ゼロ」ではなく未観測とし、GBIF記録件数も種数・個体数・森林の質の代用にしない。eBirdは使わない。

## 主張できないことと反証可能性

- 樹木被覆率が森林構造を十分に表す、とは仮定しない。
- 気候条件付きの構造偏差を人為劣化の因果尺度とは呼ばない。自然攪乱、林齢、土壌、樹種等の代替説明を残す。
- 構造を加えても地域外予測が改善しない場合は、構造の独立した追加説明力は支持されない。
- 観測支持のない森林帯や他の採集層へ一般化しない。
- 地表対枝叩きの比較は、複数の独立地域で層別の方法情報が得られない限り、全球の鉛直ニッチ比較に格上げしない。
- 個別研究の採集法差・気候帯差が重なる場合は識別限界を記録する。完全な因果識別ができなくても、支持範囲を明示した相関・予測分析は行う。

## 次に完了させる一つの成果物

**全球森林の環境母集団と、実観測が存在する地点の支持範囲を重ねた入力台帳。** 森林帯×地域×調査年代×方法×分類群の件数、同じ森林への重複、地図の時点一致、参照森林の有無を出す。ここを通じて初めて主解析の使用数を決定する。今は設計修正・出典確認段階であり、全球群集行列も森林構造の効果推定もまだ完成していない。
