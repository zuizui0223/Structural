# Occupancy-dependent isolation synthesis v1.154

## Core ecological hypothesis

> **Island isolation is partly generated by the occupancy state of the focal species.**
>
> For a focal island (i) and species (s), effective source isolation is not only a property of the physical island geography (G). It is a function of that geography and the species' occupied-source state (O_s):
>
> [
> I_{is}=F(G,O_s).
> ]
>
> When many source populations are occupied, alternative sources can make the exact arrangement of any one subset comparatively redundant. When only a few occupied sources remain, changing which islands are occupied changes the source landscape itself; the same focal island can therefore become effectively more or less isolated without any change in its physical position.

This is the ecological interpretation of the current Structural evidence. It is more specific than "connectivity matters" and narrower than a claim that graph edges represent realized dispersal.

## Why this is not just classical connectivity

Classical island biogeography usually starts from physical separation of a target island from a source region. Modern island-biogeographic work has expanded isolation to include multiple geographic dimensions, nearby islands, source pools, environmental filtering and historical isolation.

Spatial metapopulation theory goes further by allowing colonization pressure to depend on which other patches are occupied. That mathematical idea is not new. Empirical work has also shown that connectivity can be a dynamic property jointly determined by landscape structure and the changing distribution of occupied populations (e.g. Drake, Lambin & Sutherland 2022, *Journal of Animal Ecology*, doi:10.1111/1365-2656.13783).

Accordingly, Structural must **not** claim to discover occupancy-dependent connectivity itself. The present contribution is narrower: it tests whether the *incremental information in exact island adjacency* changes across species occupancy regimes at global scale, after source number, source proximity, prevalence and generic geography are already represented.

The empirical bridge is:

1. the same 5,401-island geography is held fixed;
2. species are separated into disjoint occupancy layers;
3. candidate source information is conditional on the focal species' occupied islands;
4. the ultrarare layer is tested prospectively on held-out species responses;
5. topology specificity is tested against degree- and edge-length-matched rewired graphs;
6. the conservation extrapolation from spatial source structure to future consequence is tested independently with a three-wave temporal system.

Thus the claim is not that occupied-patch connectivity was invented here. The claim is that **the information carried by island topology changes with the regional occupancy state of the species**, at a macroecological scale.

## Three predictions

### H1 — sparse occupancy exposes topology

When a species occupies very few islands, realized presence should be more sensitive to the exact arrangement of the remaining occupied sources than to source count or generic proximity alone.

Current evidence: **supported in the preregistered ultrarare mammal layer**.

- 529 species with 1–4 pilot presences.
- held-out presence C−R3 = **−0.5963**.
- actual topology minus mean rewired topology = **−0.0585** on the preregistered presence metric.
- actual adjacency outperformed **20/20** matched rewired graphs.
- graph-reachable presences showed a larger gain than graph-empty presences.

The strong reference already included bioregion, climate/topography, area, current and past external isolation, generic network context, occupancy breadth, regional prevalence, nearest occupied-source Euclidean distance and diffuse occupied-source pressure.

The residual information is therefore not reducible to "rare species have fewer sources" or "nearby sources matter".

### H2 — source redundancy weakens topology specificity as occupancy expands

As the number of occupied source islands increases, alternative sources should make exact topology less uniquely informative.

Current evidence: **supported as an observed cross-layer pattern, but not as a single prospectively tested monotonic gradient**.

- 5–12-presence layer: prospective overall non-replication; actual graph better than 11/20 nulls.
- exploratory >=13-presence layer: source-context gain concentrated in absences and actual adjacency was not uniquely informative; actual graph better than 0/20 nulls on the audited all-cell metric.
- the broad near-ubiquitous layer was non-estimable and must not be reconstructed by threshold widening.

Therefore the defensible statement is a regime shift, not a fitted monotonic rarity curve.

### H3 — spatial importance is not automatically temporal dependence

If a source island is spatially distinctive in a static occupancy network, its loss need not cause greater subsequent contraction of surviving populations.

Current evidence: **the stronger management prediction failed in the independent BALA temporal test**.

- BALA1 -> BALA2: source-loss exposure.
- BALA2 -> BALA3: later contraction/persistence.
- 20 confirmatory taxa, 64 targets, 20 contractions, 44 persistences.
- primary C−R2 = **+0.000674**.
- 95% taxon-bootstrap interval = **[−0.02130, +0.02558]**.

The descriptive leverage contrast pointed in the predicted direction, but the held-out primary did not improve and is terminal.

This is a key biological distinction:

> **source topology can structure where populations are observed without implying that loss of a topologically important source will cause downstream extinction.**

## Mechanistic interpretation

The cleanest process interpretation is an **assembly/persistence asymmetry**.

The ultrarare mammal signal sits specifically in realized presences. This is compatible with source configuration constraining colonization opportunity, historical assembly or the set of locations reachable during range formation.

The independent BALA test asks a different process question: after a source population disappears, does its prior structural leverage predict which surviving populations subsequently contract? It did not.

This combination is consistent with a long-standing metapopulation distinction between occurrence/colonization structure and local extinction dynamics. Empirical systems exist in which connectivity or network centrality predicts occupancy and colonization much more strongly than extinction. Conversely, static occupancy patterns are not sufficient evidence for rescue effects or causal dispersal.

Structural therefore must not label the mammal result as a demonstrated rescue effect. A safer interpretation is:

> **At low regional occupancy, the realized distribution retains a topology-specific source signature; whether that signature reflects ongoing dispersal, historical colonization, or another spatial assembly process remains unresolved.**

## Why very sparse occupancy is the natural regime

For any target-specific non-negative source weights (w_{ij}), define normalized source leverage

[
L_{ij}=rac{w_{ij}}{sum_k w_{ik}}.
]

With (n) occupied sources,

[
max_j L_{ij} geq rac{1}{n}.
]

Thus sparse source sets necessarily admit large individual leverage, and geographic heterogeneity can make the concentration much stronger than the (1/n) lower bound.

The response-free ultrarare diagnostic matches this expectation:

- among 212 species with 2–4 occupied pilot sources, the dominant source carried a median **66.1%** of graph-pressure leverage;
- median effective-to-nominal source-number ratio = **0.744**;
- four nominal sources corresponded to a median effective source number of **2.57**;
- observed source configurations were nevertheless **more complementary** than bioregion-matched random placements (mean observed-minus-null effective source number = **+0.282**, 95% species-bootstrap interval **0.205–0.362**).

So the ultrarare result is not explained by simple clustering of sources. Even configurations that are more complementary than random can remain strongly leverage-concentrated when only a few sources exist.

## What is genuinely new

Do not claim novelty for any of these separately:

- that isolation matters;
- that nearby islands can be sources or stepping stones;
- that occupied patches enter metapopulation connectivity;
- that graph topology can affect persistence;
- that source pools differ among species.

The stronger novelty claim is the conjunction:

> **Across a fixed global island geography, the exact topology of occupied conspecific sources becomes uniquely informative for realized occurrences only in the sparsest prospectively tested occupancy regime, while an independent temporal test rejects the simple inference that static source leverage is a general predictor of later contraction.**

This turns the paper from another connectivity comparison into a study of **when physical geography ceases to be an adequate description of isolation**.

## Relationship to existing theory

Useful anchors:

- MacArthur–Wilson / rescue-effect tradition: immigration links isolation to colonization and potentially extinction.
- Hanski–Ovaskainen metapopulation capacity: landscape topology can determine persistence thresholds and patch contributions.
- modern island-isolation work: isolation is multidimensional and historically dynamic rather than a single mainland-distance scalar.
- source-pool island biogeography: source identity and proximity influence island composition.
- empirical network metapopulations: occupancy/colonization and extinction can respond differently to connectivity.

Structural applies this established occupancy-state logic to global island biogeography and asks a more specific unresolved question: **when does exact source topology contain information beyond source count, source distance and generic island geography?** It then tests the management extrapolation separately rather than assuming it.

## Manuscript-level story

Recommended question:

> **When does island isolation become a property of the species rather than only a property of the island?**

Recommended answer:

> **When only a few island populations remain, the identity and arrangement of those occupied sources become part of effective isolation. In ultrarare mammals, exact source topology contains held-out presence information beyond physical geography and direct source proximity. But this static structural importance does not automatically translate into future dependence: an independent three-wave arthropod test found no held-out evidence that loss of a higher-leverage source caused greater later contraction.**

Recommended conservation consequence:

> **Count remaining populations, but do not assume equal spatial redundancy. At the same time, do not rank populations for protection from static source leverage alone without temporal or demographic validation.**

## What would most strengthen the paper

1. **Independent occupancy-regime replication** in a second island system, with species-disjoint or response-sealed low- versus higher-occupancy layers and a predeclared topology null.
2. **Independent transition data** separating colonization from persistence/extinction, rather than another static occurrence snapshot.
3. **Official eBird Sampling Event Data**, if obtainable, because repeated checklist effort could provide auditable island-by-time absences without inferring non-detections from occurrence rows.
4. A formal theory/simulation appendix showing why source-topology information should become identifiable as source number falls, while explicitly avoiding the claim that this guarantees demographic rescue.

## Immediate paper decision

The current paper does not need another leverage diagnostic.

The ecological center should be **occupancy-dependent isolation**, with the BALA result retained as a falsification boundary:

**pattern:** sparse species show topology-specific source information;

**process not established:** source leverage does not predict later contraction in the independent temporal test.

That asymmetry is the result, not an inconvenience.
