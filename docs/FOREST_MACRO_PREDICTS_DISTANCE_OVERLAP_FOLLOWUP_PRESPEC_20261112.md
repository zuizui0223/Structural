## 先にメタデータのみで決める幾何学的共通支持

39元研究の正規化前Original SITE summaryを使用、元研究内のすべての参照–参照(RR)地点対と改変–参照(AR)地点対の地理距離を計算。各AR対の距離dに対し、同研究RR距離のうち最も近いものとの log 距離差を測る。

- 距離比の許容幅：0.667–1.50倍（abs(log((ARkm+0.05)/(RRkm+0.05))) ≤ log(1.5)）。
- 元RR地点が最低**3個**存在し3組以上のRR比較ができる。
- 許容内のAR組が最低**5組**存在し、その元改変地点と参照地点がそれぞれ**2地点以上**存在する。
- 生物応答を一切見ず適格群数を確定。**10研究以上**が適格な場合にのみ、距離を揃えた探索的な二次生物感度解析を実行検討。10研究未満なら **SCIENTIFIC_STOP_DISTANCE_COMMON_SUPPORT_INSUFFICIENT** とし、有利な閾値へ事後変更しない。
- 地点座標は著者由来かジオリファレンス由来かで精度が異なる。10 mの厳密マッチを捏造しない。
- 数値は元研究等重み、観測地対ではない。位置・元地点・元分類群名・元測定値は出力しない。

## 生物再訪の条件付き仕様（未実行）

もし適格研究数10以上なら、別途同じPREDICTS原本のTaxon_Number/Measurementと元地点を再結合し、各許容AR対に距離が最も近いRR対（同じ元研究内・再利用可）を対応。**距離対応したSimpson置換差**をStudy単位で平均して記述。独立研究間cluster bootstrap 4,000と元study sign-flip 9,999を感度評価として提示するが、一次解析と独立に確認的・有意差判定を重ねない。βで有利な対・森林・閾値を後から選ばない。

距離一致は環境・調査年・habitat管理の因果交換可能性を担保しない。群集分類の新規性は古くからPREDICTSの分析対象であり、マクロ一般則や森林構造／林冠高さの直接検証ではない。既存のBALA/GEB/THERA凍結データに一切触れず、eBird不使用、Draft PR #469未マージ。
