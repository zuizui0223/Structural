# Zarges temporal biotic history: outcome-blind method refinement (2026-11-24)

Public original author methods independently reread: https://doi.org/10.1111/1365-2664.70479, sections 2.1–2.3; source README https://doi.org/10.5061/dryad.k6djh9wns (2026-06-22). Experimental logs were treated after first bark-beetle colonization, and each season's emergence trap was relocated 50 cm. The authors pooled multi-year incidence, excluded initial-detected microbial OTUs in the published post-treatment analysis, and used initial-to-final wood changes. The proposed prediction must instead use only past information and annual observations. Initial microbial time I is not automatically proven pre-treatment; require date provenance. The public README explicitly describes a July 2023 canopy-cover change in three treatment logs at one site; FC/CC timing cannot be assumed universally pre-2023. HV2 README and manuscript dose descriptions differ; use literal categorical treatment identity only.

## One primary question, refined before any future biological count access

Does **October 2022 fungal identity**, not just the amount/diversity of observed fungal detections, improve prediction of 2023 saproxylic beetle composition in an entirely held-out forest site? This is a prospective specification refinement, not a result.

If the source supports valid annual sample opportunities, library QC and dated covariates:
- R0: categorical original treatment, pre-target physical wood attributes and climate, observed trap area/duration as observation offsets/covariates; no 2023 canopy change or final wood differences.
- R1 (primary reference): R0 + 2022 beetle community + autumn 2022 fungal observed OTU richness and sequencing depth if available, plus initial fungal composition if verified as an earlier measurement with adequate coverage. Exact initial-state support and final covariate roster must be fixed from method and nonresponse metadata before target access; if required information cannot be established, do not claim a residual identity-specific gain.
- C: R1 + autumn 2022 fungal OTU identity. Use incidence-derived normalized community representation to avoid calling PCR reads biomass. Whole forest site holdout; training-only transformation, feature construction, penalties, and any dimensional reduction. No test response in taxon learning, tuning or preprocessing. Explicitly score genuinely sampled empty beetle rows, but failed/missing sequencing libraries are not empty communities. If an observation record is missing, not an assumed zero.

Primary contrast: held-site mean prediction loss(R1) - loss(C) for a fixed Hellinger-relative incidence+explicit-empty community vector, equal site weighting. No extra claim from changing endpoint, selected subsets, bacteria, or alternate years. The precise numerical estimator and inclusion/missingness thresholds still need to be frozen after a successful original source-only audit. Preserve separate year/site holdouts. A positive gain is predictive information, not a causal fungal-beetle interaction; a shared unmeasured resource or prior colonization can cause the association. A non-positive gain does not rule out fungi as an ecological mechanism.
