# Independent source-loss leverage validation protocol v1.125

## Why three waves are required

The conservation hypothesis is about what happens **after a source population is lost**.

A two-wave design cannot cleanly separate exposure and consequence. If source loss and target-population loss are both defined from the same t0→t1 transition, the analysis cannot tell whether source loss preceded the contraction it is supposed to explain.

The minimum clean temporal structure is therefore:

- **t0** — freeze occupied sources and their leverage;
- **t0→t1** — observe which source population is lost;
- **t1→t2** — score subsequent persistence or contraction of other island populations.

The lost source itself is never counted as its own downstream target.

## Primary conservation prediction

For otherwise comparable source-loss events:

> **Losing a source that accounts for a larger decrement in effective source number should predict greater subsequent contraction of other occupied island populations.**

The comparison must hold constant, or explicitly represent:

- nominal number of sources present before loss;
- number of source populations lost;
- Euclidean source distance;
- external island isolation;
- habitat/environment;
- archipelago or bioregion context.

The preferred primary design uses events with exactly one source population lost, because then “one population lost” is held fixed and only leverage differs.

## Why leverage is better than source count for this test

The current ultrarare mammal diagnostic shows that nominal source number and spatial leverage are not equivalent.

Among species with 2–4 occupied pilot sources:

- median dominant-source leverage share = 0.661;
- median effective/nominal source ratio = 0.744;
- four nominal sources correspond to only 2.57 equally influential sources at the median.

Thus a future temporal test should not ask only whether one versus two populations disappeared.

It should ask whether the **particular source that disappeared** was spatially redundant or irreplaceable.

## Primary endpoint

The primary target is a population occupying an island at t1.

The outcome is whether that population persists to t2.

A strong reference contains environment, island state, external isolation, generic network context, source count, number of source losses and ordinary remaining-source proximity.

The candidate adds only the pre-loss leverage of the source that disappeared.

The primary statistical question is whether that leverage term improves heldout prediction beyond the strong reference.

## What success would mean

A successful independent test would justify:

> loss of high-leverage source populations carries more future occupancy information than population count and ordinary distance alone.

It would **not** by itself prove:

- dispersal along graph edges;
- demographic rescue;
- causal prevention of extinction;
- that restoring the same source would reverse the effect.

Those require movement, demographic, genetic or intervention data.

## Admission rule

No existing Structural system can count as confirmation of this hypothesis.

A future dataset enters only if it provides:

1. at least three ordered occupancy waves;
2. a response-independent island geometry;
3. source identity at t0;
4. a source-loss exposure window t0→t1;
5. a later target outcome t1→t2;
6. a disjoint burned pilot for estimability;
7. a frozen leverage operator and validation design before confirmatory t2 access.

The current global mammal dataset is closed to this test.
