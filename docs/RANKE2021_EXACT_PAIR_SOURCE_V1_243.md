# v1.243 Ranke original island pair source identity

Ranke et al. 2021 already found effects of distance and farm/non-farm habitat on sparrow natal dispersal. The published Dryad version 2 (ID 136299) lists island-pairs.txt and description.txt. Original source size and SHA256 are frozen in the script and were taken from the independently successful v1.242 metadata receipt.

This protocol tests three publisher-owned download routes for the exact same file IDs. It accepts a file only if original size and SHA256 both match. It reads only the first header row of island-pairs.txt and the original author description, not numerical geography or migrant outcomes. A 401/403 or checksum failure is technical STOP; never infer distances from island names or use another version.

The v1.241 source-pair improvement disappears when Sleneset is removed from later scoring, and distance has not been included. A successful author original distance matrix plus all 11 matching population island IDs is a prerequisite for a distance-conditioned route-prediction comparison. Main GEB hold unchanged.
