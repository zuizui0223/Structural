# 林冠と甲虫の垂直分化：タイForestGEO原データの初回実測解析（2026-11-08）

## 現在地・研究結論

**肯定的な地域結果**：タイの2森林（Mo Singto, Khao Yai と Klong Naka）で元のForestGEO 9調査地点／森林、2採集期、各地点林冠・下層のSLAM飛翔昆虫トラップによる甲虫1,622個体を再解析すると、林冠899個体、下層723個体。林冠／下層＝**1.2434倍（+24.3%）**。2森林×2採集期の4層比較でいずれも林冠側の合計が高い。

**原データの証拠**：GBIF dataset `7ba1318c-04ed-4521-8369-63731e2867f7`、DOI **10.15468/92ca8u**、元DwC-A SHA256 `1565cf6d7f1e7289e28756367e3d137f64723dc1fa0a06d799f6abdb523e1339`。公開CC-BY 4.0。原本Event 288、Occurrence extension 1,073行、`individualCount`計1,622。甲虫は**SLAM 144 jar Events**のみで捕獲（林冠72 jar Events、林床72）。ライトトラップ・黄FITと混同していない。元SLAMは高さの異なる林冠・林床の2層、それぞれトップ／ボトム採集瓶で捕捉する。個体数0のsource Eventも相当するサンプリング努力として含めるが、全Eventで元採集努力メタデータを監査し林冠・林床で完全一致を確認。

### 元調査地点・採集期で揃えた検定

まず原座標だけを用いて、林冠・林床の**9×2森林＝18地点**を最短距離で一対一対応（相互最近傍、全距離60m以下：実際の最大はKhao Yai側33.37m、Klong Naka側42.02m）。各地点で2採集期を区別し、同じ層の**トップ／ボトムの採集瓶を同じトラップとして統合**。最終36地点×採集期ペア。推測の単位は採集瓶144でも季節を繰り返した36行でもなく**18物理調査地点（2森林内に各9地点）**。

| 指標 | 観測結果 |
|---|---|
| 合計林冠 / 林床個体数 | **899 / 723** |
| 同じ地点・採集期での平均差（林冠−林床） | **+4.8889個体** |
| 各地点の2採集期平均差が林冠優勢 / 林床優勢 / 同数 | **12 / 3 / 3地点** |
| 地点平均の厳密な二側符号反転検定 | **p=0.00439453125** |
| 2森林それぞれ9地点を再抽出する層化地点bootstrap 95%区間 | **+2.3056〜+7.6111個体／地点／採集期** |
| 森林1の合計 | 林冠302 / 林床262（同森林内5/9地点が林冠優勢） |
| 森林2の合計 | 林冠597 / 林床461（同森林内7/9地点が林冠優勢） |
| 森林1の第1/第2採集期 | 200/170、102/92（林冠/林床） |
| 森林2の第1/第2採集期 | 421/346、176/115（林冠/林床） |

**支持範囲の厳格な解釈**：`p=0.0044`は2森林で観察した地点についてのみ、層ラベルの交換可能性を前提にした探索的な地点内符号反転検定であり、**森林間の独立再現 n=18、熱帯林を代表した p値、因果的高さ効果ではない**。森林間独立単位は**n=2**。地点を束ねた効果は季節内で標準化された相関であり、観測地以外の一般性・持続性は別地域の検証が必要。

### 科レベルの群集組成

原データの生物分類は `taxonRank` genus 677行、subfamily 200、family 86、order 62、species 48（明確な`specificEpithet`は0）。**異なる同定階級を種として混在して数えない**。科名末尾`-idae`の正規化した`family`だけを分類群単位とし、解析不能な科は欠測扱い（72出現記録行）。

- 林冠で確認できる科ラベルは**50**、林床では**45**。両層共有**37**、林冠のみ**13**、林床のみ**8**。個体数の多い層は科の検出機会も多くなるため、これは**希釈補正後の科多様性差ではない**。
- 相対個体数に基づく科組成のBray–Curtis非類似度（2森林プール）＝**0.2942**。同一地点・同一採集期の双方に識別科が存在する**36ペアの平均Bray–Curtis＝0.5478**。これは階層を揃えた構成差の**記述値**であり、検出・標本数・地点内ばらつきを明示した帰無比較はまだ行っていない。
- 林冠で多かった科：Curculionidae **369 vs 246**、Cerambycidae **65 vs 20**、Chrysomelidae **72 vs 31**、Ptinidae **42 vs 19**。
- 林床で多かった科：Throscidae **12 vs 92**、Nitidulidae **1 vs 33**、Staphylinidae **39 vs 55**。甲虫の全科に一様な林冠選好があるわけではない。

### 森林生態学・島嶼生態学への位置づけ

この解析で**直接支持**されるのは、同じ森林・季節・採集法・地点を揃えると、**林冠における飛翔甲虫の捕獲個体数が下層を上回り、科組成にも垂直的な差がある**という局地的な結果。捕獲率／飛翔活動に依存するので、同一面積の森林の甲虫総生息密度や全種数を示すものではない。

林冠の樹高、被度、光環境、樹種組成は**この比較では説明変数としてまだ使用していない**。樹冠が高いほど多い、林冠の複雑性が種多様性を増す、という因果推定も未実施。ForestGEOの元20m×20m樹木区画に紐づけて初めて、樹高・樹種・葉量と甲虫の対応を別途評価できる。実測の垂直分化を、林冠構造の因果作用や単一種の垂直ニッチと同一視しない。

島嶼の既存5,401島・哺乳類529低占有種では供給源配置が実在presence予測を改善した。ただし**森林の垂直甲虫分化は空間パッチ間の供給源移動と別の機構**。関連を検証するなら、森林（外部の分断・マトリクス）×森林内の林冠構造（垂直資源）×同定精度の揃う甲虫群集、という独立した因子を組み、個別の供給源経路効果は別に検定する。

既存のBALA/SLAMアゾレス地表・枝叩きは**地表pitfall vs 約1.5–2m枝叩き**で、タイの**地上約2mに設置したSLAM vs 林冠直下SLAM**とは別の採集法／垂直層定義。BALAの標高×在来/外来構成差をタイ甲虫の同一機構と呼ばない。

## まだ必要な次段

**第一優先**：同じ地点のForestGEO樹木組成・樹冠高・地表からの高さ・光/微気候を、元フィールドIDと照合して入手できるか監査する。各地点の木本資源環境と、同じ採集努力の甲虫群集分化の関係を検証する。

**第二優先**：公開甲虫は大半が属/亜科止まり。種/モルフォ種コードが一意に対応する元リストを取得できる場合にのみ、種レベルのβ多様性・採集階層特異性へ進む。元資料は「morphospecies data on request」と明記されている。

**第三優先**：2森林だけでは全球の一般則を推定不能。他の熱帯・温帯・乾燥林の同一採集法データを固定し、森林タイプ外ホールドアウトで検証。eBirdを使わず、GEB哺乳類の元凍結スコアは開かない。
