# Connectivity state ladder v0.3

## Purpose

v0.3 converts the Structural↔EGWE methodological spine into a prospective empirical sequence.

The question is no longer only whether a connectivity coordinate adds information. It is:

> **How far must the present-state representation be enriched before spatial origin/history no longer carries a meaningful residual for the declared endpoint?**

## Ladder

The declared order is:

    current ecological reference
        ↓
    structural geometry
        ↓
    process-model connectivity
        ↓
    realized connection
        ↓
    origin/history residual

The four tested additions are:

1. **structural geometry** — source configuration, graph position, stepping stones, adjacency, distance-derived structure;
2. **process model** — a biological operator is declared, such as pollen flow, individual movement, allele movement, recolonisation, or interaction continuity;
3. **realized observation** — directly observed movement, pedigree/gene flow, pollen transfer, recolonisation, or another realized connection;
4. **origin/history** — pre-existing isolation, habitat fragmentation, urban origin, or another history label added only after the best current state is supplied.

Intermediate stages may be unavailable and can be omitted, but the supplied stages may not be reordered.

## Why non-significance is not state sufficiency

A failed residual-origin test does not establish that the current state is sufficient.

If the origin/history confidence interval crosses zero, the result is **indeterminate** unless an equivalence margin was frozen before outcome access.

State adequacy is earned only when:

    CI(origin increment) is fully inside [-epsilon, +epsilon]

where epsilon is the predeclared smallest meaningful residual effect.

This is the key EGWE precision lesson imported into Structural methodology: an unresolved null is not equivalence.

## State outcomes

### state_adequacy_earned

The origin/history increment is bounded entirely within the predeclared meaningful margin.

Interpretation:

> For this endpoint, reference and declared operator, origin/history contributes no residual effect larger than the frozen meaningful threshold.

This is not universal state sufficiency.

### origin_residual_earned

Origin/history still adds held-out information after the best declared current state.

Interpretation:

> The current state remains incomplete, or origin/history is proxying an unmeasured process, cohort, alignment, memory, or connectivity coordinate.

This does not prove history itself is causal.

### origin_residual_adverse

Adding origin/history reliably worsens held-out prediction.

This is an informative negative result but is not automatically an equivalence statement.

### origin_residual_indeterminate

The interval overlaps zero and does not fit inside a predeclared equivalence margin.

No state-closure claim is allowed.

### origin_not_tested

The ladder has not reached the residual-origin gate.

## Original isolation and fragmentation

The same ladder can be used in:

- pre-existing island isolation;
- habitat fragmentation;
- urban fragmentation;
- other histories.

Each ladder is system/operator/endpoint specific. The resulting effect sizes are not pooled merely because the same ladder was used.

## Relationship to v0.1 and v0.2

v0.1:

> one scalar connectivity label can hide operator-specific state.

v0.2:

> the operator-matched connectivity coordinate recovers held-out information and the winner reverses with endpoint truth.

v0.3:

> after progressively supplying geometry, process and realized connectivity, test whether origin/history retains any scientifically meaningful residual.

Thus the development sequence is:

    scalar insufficiency
        → typed operator state
        → operator-matched prediction
        → state ladder
        → residual history/equivalence gate
        → cross-system comparison only after per-system closure

## Frozen-paper boundary

No v0.3 object changes the A-Islands or Tanzania results. Those systems remain historical empirical examples of reference-conditioned structural adequacy. Future v0.3 empirical tests require a new, separately frozen protocol and cannot be used to rescue the current paper.
