## One next forest macroecology question — UK-wide observation frame before biology

After the independent Carpathian116 observed larval guild + deadwood LOSO exploratory **non-support** (frozen [result](FOREST_MACRO_CARPATHIAN116_WEISS170_GUILD_DEADWOOD_LOSO_ONEPASS_ACTUAL_RESULT_20261118.md)), the next scientific mainline is not to retune negative models. We need an **independent geographical field cohort** with original sampling layers, method, place/year and tree-resource variables. The newly discovered England NFI collection is a candidate for the **geographic field observation component** only. It is NOT yet a tested vertical refuge/resource-lock mechanism.

Authoritative publisher: Forestry Commission / Defra Natural Capital and Ecosystem Assessment **NFI Canopy & Subcanopy Arthropod Communities**, original dataset UUID `2b8a8f17-3745-43d1-bb32-0d509230f158`, publication Dec 2025, revision **2026-09-08**, original 2023–2026 England field program; [Defra official source registry](https://environment.data.gov.uk/natural-capital-ecosystem-assessment/search/2b8a8f17-3745-43d1-bb32-0d509230f158), [National Data Library](https://www.data.gov.uk/dataset/6e0ca4e8-9446-4cac-ab51-b70c847fbba2/nfi-canopy-subcanopy-arthropod-communities).

Biological OTU read counts are not arthropod individual abundances.

## Prespecified source-only first execution

1. Download **only the literal official 2023–2026 data ZIP** through an ordinary publisher GET, not an older 2023–24 cached copy, mirror, guessed CDN, credential, or private interface. Cap transfer at 1.5 GiB and require valid ZIP; first archived SHA256 and byte size are newly discovered integrity receipts, **not** pre-known hashes or organismal scores. On access/size/HTML/malformed ZIP, record `SOURCE_TRANSPORT_OR_ARCHIVE_STOP`, retain zero biological results, do not attempt alternative URL. Do not fetch the separate evidence ZIP or PDFs in this first gate.
2. Inspect only ZIP central directory and the **first CSV/TSV header line** of candidate data-table files, never the body rows, names/values of original taxa or taxa-by-site matrices, sample-specific coordinates, delocation ID values or OTU sequence. Return bounded aggregate entry count, file extension histogram, compressed/uncompressed byte totals and boolean header-family presence with field counts. No file/member name that could expose site or taxon IDs is exported.
3. Freeze source columns **as potential candidates**, not as verified sample-site keys. A delocation cell is a masked geography unit, not an independent original NFI physical woodland plot. Same delocation ID does not automatically imply two vertically paired traps; the source must expose author physical plot/replicate ID, sample date and effort to qualify paired analyses. Check these keys in a later, separately precommitted metadata-only step.
4. Source trap confounding is fatal to naïve vertical effects: **Lindgren canopy vs Malaise subcanopy** contrasts layers AND trap selection, so raw assemblage differences cannot prove stratification and must not be compared numerically to Thailand SLAM matched-height or Brisbane FIT strata as though methods were equal. UK-wide within-`method × forest type × field network` gradients can be described if genuine original effort and independent site IDs are available, with paired layers treated as **method-conditional detection assemblages** only.
5. No direct plot-level microclimate, deadwood, true canopy height, tree-resource identity/abundance, true original coordinates or 3D dispersal operator is claimed to be available from published registry text. Field evidence might ultimately permit **geographic replication** of detected community differences under tree types; the fuller three-dimensional realized-niche test needs separately paired temperature and resource measurements. Predefine sample-level and tree-identity availability before any species/OTU rows are opened.
6. Keep the PREDICTS 39-study +0.0942, Finland142 Host_tree deadwood +0.00024237, Carpathian116 trophic-guild negative -0.00106793, German Chiu and Thai results frozen and non-pooled. **Do not** read or rescore old BALA, GEB, NEON or heldout responses; no eBird, no TinyFish, no main merge.
