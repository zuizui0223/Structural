# Steigerwald six-plot beetle x host-tree x shade experiment: PREBIOLOGY source hierarchy protocol (2026-11-17)

## Authored source (not Structural's novelty)
Original author's public data and code [AnneChao/PTB_iNEXT.link](https://github.com/AnneChao/PTB_iNEXT.link), Chao/Chiu/Vogel/Kriegel/Thorn 2023, original Dryad dataset DOI 10.5061/dryad.ksn02v78d (the GitHub source is explicitly cited as an alternative in the author's README). Source is a historical German **one-forest Steigerwald** experiment, SIX parent plots, 3 source shade treatments G (closed forest), N (net shade), O (open sun), SIX offered deadwood tree hosts, FOUR years (2016–2019). Original README reports 3,891 rows, 264 beetle species and 9 fields; authors previously analyzed tree-beetle network diversity. Do not call a positive host association a new ecological discovery, cross-country replication, or spontaneous field experiment.
