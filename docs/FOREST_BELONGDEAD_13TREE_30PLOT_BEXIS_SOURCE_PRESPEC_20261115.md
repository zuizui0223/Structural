# German BELongDead 13-tree × 30-forest original experiment: source-access and independent-study eligibility gate (2026-11-15)

## Scientific target and why this source outranks pseudo-replications

The prior Finland 142-author-site Host_tree conditional-null difference remains fixed D=+0.035237, and adding original local total deadwood author z-score VD10 improved out-of-geographic-block 3-guild Hellinger² loss by **+0.00024237** (9 cells, conditional p=.015), a modest retrospective same-source association. New original source must contain **genuine known host tree identities, source plot/log identity and species-by-host log beetle incidence with sampling effort/time**, and enough replicates to estimate physical-plot/log dependence.

German **Biodiversity Exploratories BELongDead** original experiment established approximately **13 log tree taxa/species × 30 forest plots nested in 3 Exploratories**, originally logs placed ca. 2009 and emergence sampling from 2010 onwards. Original source dataset names and IDs listed by the official BE project catalogue:
- **BExIS 31123**, version/tag 1: Achury, Seibold, Simons, Goßner, Weisser (2023), *Beetles on different tree species, all forest VIPs, normal subplots, 2010 to 2017, BELongDead*.
- **BExIS 31124**, tag 1: same study/source series, *Saproxylic beetles ... 2010 to 2017, BELongDead, logs with complete data*. This is a subset/filtered view of the same experiment, **NOT an independent 2nd study**. Do not pick the subset based on a biological signal. Prefer source-full 31123 if accessible and author effort/valid-log indicators are verified.
- **BExIS 30981**, tag 1, 2008 beetle data from **43 forest plots**, and **30979**, tag 1, 2012/2017 deadwood inventory from 43 forest plots: DIFFERENT study/time and unsuitable as same-year host-use validation without explicit forest plot correspondence and temporal lag control.

Source data availability and official API provenance: [BE published project catalogue](https://www.biodiversity-exploratories.de/en/projects/core-project-7-land-use-above-ground-arthropod-diversity-and-arthropod-affected-processes/), [BE public data policy](https://www.biodiversity-exploratories.de/en/public-data-bexis/); the BEXIS2 project documents public dataset REST access at `/api/dataset/{id}`, original metadata at `/api/metadata/{id}?tag=1.0`, original data at `/api/data/{id}`. Dataset portal access is via `www.bexis.uni-jena.de`. The BE project says most public data are CC BY4, but **this is NOT proof of any particular dataset license**. Verify actual individual source rights first.

### THIS source-only action, frozen before biological access
1. Query exactly the above original **four** BExIS IDs at the official public BEXIS host via documented **/api/dataset/{id}**, with bounded 25s timeout each, keep all retrieved content runner-private. Report only HTTP status, redirect status/url origin class, JSON/HTML content type, returned document size and non-sensitive dataset metadata fields where present. Do not brute force API hosts, login, cookies, credentials or mirror URLs.
2. Only when 31123/31124's actual original **dataset license and public data access** can be explicitly verified from the dataset/metadata response should a subsequent separately recorded dataset table **schema** call be allowed; this gate itself does **not** fetch species/capture records or host-log values.
3. A 401/403 or public portal error is an **access STOP**, not ecological non-support. 429/502/timeout is a **transport/source STOP**, not proof that rights are restricted; do not loop indefinitely.
4. No source-subset cherry picking: 31124 is source completion view of the same 31123 experiment. Also 2008 beetle versus 2012/2017 wood are time-offset observations; no pooled contemporary host-resource claim.
5. The project’s prior 2016 original publication [*Deadwood enrichment in European forests – Which tree species should be used to promote saproxylic beetle diversity?*](https://www.sciencedirect.com/science/article/pii/S0006320716302567) already reported >70k individual beetles / >400 species across 13 tree taxa and 3 German regions and examined early decay host tree/richness effects. A simple claim “beetles differ among host trees” is **prior art**. Only a separately frozen design on *resource-use guild complementarity conditional on original plot × tree host × age*, with appropriate 30-plot/hierarchical uncertainty, could advance the cross-site mechanism and must not be tuned to positive outcomes.
6. Never download, score or post raw original beetle taxa, trap or sample values in this source-only gate. All previous source 12-year ID mismatch, Sweden Dryad HTTP401, Poland original plot collision hold and France/Germany 98-plot aggregated-tables restriction stand. Preserve Finland, 3-country Burner, PREDICTS, NEON, BALA, GEB results; eBird/TinyFish unused, Structural PR #469 Draft/unmerged.
