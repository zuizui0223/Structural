# Boreal birds topology-sensitivity test v1.158

## Why this route

The fresh 19-island beetle primary is closed and non-supportive. It tested an **overall** graph-path increment beyond R3. It did not test the later occupancy-regime mechanism that emerged from the global mammal sequence.

The bird matrix was prospectively listed as a secondary taxon before the beetle response was opened, but no bird scoring execution is present in the repository. This route therefore uses the still-sealed bird response for a new, explicitly different question. It does not reopen beetles and cannot rescue the failed beetle primary.

The geography is not independent: birds and beetles share the same 19 islands. The response is taxonomically independent.

## Prediction

The response-free finite-source identity gives:

**S_i(n) = [(M−n)/(n(M−1))] × H_i**

with M = 6 frozen pilot source candidates and H_i = σ_i²/μ_i² for target-specific source weights.

For this 19-island geometry, H_i ranges from about **0.523 to 2.696**. Most confirmatory targets are near the upper value. Therefore the strongest response-free prediction is driven by source scarcity:

- n = 1 → finite-source factor 1.0
- n = 2 → 0.4
- n = 3 → 0.2
- n = 4 → 0.1

The bird test asks whether exact topology is most useful for realized presences on prediction rows with high S_i(n).

## Why this differs from the failed beetle test

The beetle primary averaged C−R3 across all fixed species and both outcome classes. A universal graph-path benefit was not supported.

The bird primary instead requires two conditions on **realized presences**, weighted by a response-independent mechanism score:

1. actual graph-path C must beat R3;
2. the actual graph must beat 20 degree- and edge-length-bin-matched rewired graphs.

Both conditions must pass. Nulls and the S formula are frozen before any bird response opens.

## Null graphs

The 19-island actual graph has 35 edges and k = 3.

A response-free dry run established that 20 distinct connected null graphs are feasible while preserving:

- every node degree exactly;
- the exact count of edges in each of five actual-distance quintile bins;
- 35 total edges;
- no self edges;
- no duplicate edges.

Each null receives exactly 70 accepted degree-preserving double-edge swaps under a deterministic SHA-256 scheduler. The actual kernel scale is reused so adjacency is the only candidate-graph property intentionally changed.

## Evidence status

This can become a **same-geography, different-taxon prospective replication** if the bird pilot and confirmatory gates pass.

It is not geographic replication and cannot establish a universal island-biogeographic law by itself.

## Stop rules

The route stops without confirmatory access if fewer than 12 bird species have 1–4 pilot presences.

After confirmatory access, fewer than three spatial blocks containing eligible realized presences is terminal non-estimability.

No threshold, S definition, null ensemble, outcome class or reference tier may be changed to rescue the test.
