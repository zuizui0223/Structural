# v1.247 — Can Fox's 2017 microcosm observations identify a donor-loss feedback?

Fox et al. (2017), [Nature Ecology & Evolution 10.1038/s41559-017-0271-y](https://doi.org/10.1038/s41559-017-0271-y), already experimentally demonstrated the spatial hydra effect on **predator metapopulation persistence** under strong dispersal. The associated original dataset [Dryad 10.5061/dryad.2rs23](https://doi.org/10.5061/dryad.2rs23) publishes a ~324 KB experimental CSV and ~1.4 KB README, based on public portal metadata.

A second, distinct v1.247 source-only action verifies the publisher's exact DOI, published version and both filename/length/SHA-256 identities. It attempts to read **only original README text**, never a biological CSV record or numerical effect. Note that these data were published and the original spatial hydra result was reported by the authors. Access to a file does **not** qualify the same experiment as a fresh Structural v0.31/v0.42 replication.

Ecological measurement criterion: the mathematical v1.246 donor-source feedback term needs a specific recipient's **effective migrant delivery states from each separate source at a fixed lag** before/after source removal, NOT merely predator patch counts, synchronized cycles or treatment-level global persistence time. If Fox's dataset only contains experimental treatments and patch predator densities with no verified actual donor-to-recipient identities, it can evaluate published perturbation/synchrony and persistence findings, but cannot measure this new donor-delivery decomposition without additional data. Respect identical independence units, extinction event timing and prey/detection process. Across studies Matter & Roland 2010 observed increased synchrony after removal but NOT increased actual global extinction rate, so do not pool it as a second persistence-effect estimate.

The previous v1.203 Structural known-truth result already shows higher-order source cofailure is not identified by pairwise source covariance. v1.246 tests a different exact direct-loss versus post-loss joint response identity and does not claim biological observation. GEB remains scientific HOLD; no eBird, no original mammal heldout labels/predictions.
