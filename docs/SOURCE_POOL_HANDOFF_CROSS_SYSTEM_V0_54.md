# Cross-system source-pool synthesis v0.54

## The island-ecology question has changed

The original working idea was a strong **source-pool handoff**:

> as mainland isolation becomes extreme, occurrence support should shift from mainland/state variables toward continuity with occupied insular sources.

A-Islands generated this idea. The new mammal stress test now puts an important limit on it.

## What A-Islands says

A-Islands remains discovery evidence.

Its frozen exploratory results show that:

- ordinary islands are largely described by island area, mainland distance and direct/diffuse source context;
- source-conditioned network information becomes conspicuous in the remote tail;
- remote-but-linked and remote-and-unlinked islands are ecologically distinguishable;
- multi-hop occupied-source continuity marks residual occurrence support beyond nearest-source distance.

That pattern motivated the hypothesis that extreme remoteness changes the effective source pool.

## What the atoll test says

The Indo-Pacific atoll plant system never tested the hypothesis.

Its burned pilot encountered a response code outside the frozen endpoint domain and stopped before estimability or ecological scoring.

It is neutral for the ecological direction.

## What the 318-island mammal stress test says

This system is independent of A-Islands but is stress-test evidence, not pristine confirmation.

The source-pool coordinate improved heldout log loss descriptively:

- extreme islands: C−R3 = **−0.05593**;
- non-extreme islands: **−0.10138**;
- overall: **−0.08964**.

So occupied source pools clearly carry useful information in this heldout stress surface.

But the predeclared regime-switch contrast was:

**+0.04545**, 95% cluster-bootstrap CI **[−0.00319, +0.08836]**.

The prediction required a negative contrast.

Therefore the stress test does not support the claim that source-pool information becomes more useful specifically at extreme continent isolation.

## Revised ecological picture

The strongest current island-biogeographic interpretation is:

> **Mainland isolation and source isolation are distinct, but mainland remoteness is not a universal switch controlling the value of the occupied insular source pool.**

This keeps the genuinely interesting part of A-Islands while dropping the over-generalization.

A species' effective island source context may depend on several interacting properties:

- dispersal mode;
- archipelago permeability;
- historical land connection;
- occupancy breadth / source saturation;
- taxon-specific persistence or colonization history.

The next independent system should distinguish these prospectively rather than asking again whether "remote" alone is the switch.

## Evidence hierarchy

- A-Islands: hypothesis-generating discovery.
- Indo-Pacific atoll plants: terminal unscored fresh attempt.
- 318-island mammals: independent heldout stress evidence, primary regime switch unsupported.
- 5,592-island mammals: pristine response-sealed HOLD; no response opened.

No item currently constitutes fresh confirmation of a universal source-pool-handoff effect.
