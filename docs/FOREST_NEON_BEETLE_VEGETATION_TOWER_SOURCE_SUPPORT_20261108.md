# NEON甲虫・植生構造・多高度気温：公開メタデータの独立検証支持範囲（2026-11-08）

## 結果と現在地

NEON公式の公開API /products を2026年リリースに固定し、2018–2023年の3製品で**同一SITE×調査年**、さらに同じ年のオサムシ観測月とタワー温度観測月の一致まで監査した。[原APIを実際に照会したCI #42445708654](https://github.com/zuizui0223/Structural/actions/runs/42445708654) はSUCCESS。

| 原NEON製品 | RELEASE-2026、2018–2023に少なくとも1公開月があるサイト数 | サイト×年 |
|---|---:|---:|
| DP1.10022.001：地表性甲虫のpitfallと種／モルフォ種同定 | **47** | **279** |
| DP1.10098.001：植生・樹高等の実測構造 | **38** | **193** |
| DP1.00002.001：タワー内多高度吸引式気温 | **79** | **473** |
| **3製品の時空間支持の交差** | **38サイト** | **192サイト×年** |

3製品の公開月が同じ年に存在し、その年の甲虫とタワー気温の公開月が少なくとも1件重なる候補が38サイト・192サイト×年。年ごとの候補数は2018=26、2019=33、2020=28、2021=34、2022=35、2023=36。甲虫観測月と気温観測月が同時に公開されたサイト×月の合計は各年150、198、153、194、204、207（合計1,106）である。これらは**観測ファイルの公開可能性**であって生物応答の行数ではない。

## 生物学的な独立性と測定の境界

- 38サイト全部が森林ではない。植生構造製品は森林や低木地を含むので、元観測プロットごとに森林生息地を判定する必要がある。実際の森林調査区画数は**未確定**。
- 甲虫は主に地表pitfallであり、**林冠と林床の2層トラップではない**。塔の温度は様々な高さで測られるが、甲虫pitfallと同じ区画の微気候であるとは限らない。温度変化によって甲虫が上下に移動したと推論しない。
- 2018年に甲虫の設置努力が10プロット/サイト×4トラップから3トラップに変化したため、2018–2023年に範囲を限定。年度・試料処理・同定段階の差や採集時期を改めて監査する必要がある。
- 2森林のタイ林冠SLAMと、8か国13景観のNardi lure-funnelは捕獲法が全く違う。NEON pitfallとの生個体数をプールしない。森林の全体的な構造×地表性甲虫の種同定を、同じNEONネットワークで比較する独立系としてのみ位置付ける。
- ネットワーク別の公開地点サポートは豊富だが、今回のCIは**3つのpublic products metadataだけ**を取得した。NEON公式の /data /data/query はAPIトークンが必要（公式資料 https://data.neonscience.org/data-api/endpoints/data/）。未取得の生物応答、樹高、温度時系列に関して効果サイズ・新しい肯定結果はゼロ。
- 元原著の森林甲虫の供給源移動・将来局所消失予測の検定ではない。マクロ普遍性の判定には森林ハビタット・元プロットの独立性・実際の採集年の組成・同定階級を統一する。
