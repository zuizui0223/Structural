# v1.226 — Is *location* of prior detected sources informative for observed predator reappearance?

Following the predeclared v1.225 author-assay provenance check, which is not yet resolved, this **separate predator-only** experiment evaluates existing source-lag geometry without claiming prey-adjusted mechanism or biological occupancy. The source has already been fully opened in v1.222. Nothing here becomes pristine confirmation or authorizes a manuscript promotion.

**Primary retrospective prediction:** restrict to pairs (t,t+1) where predator Euplotes sample at patch j was exactly zero at visit t, score next-visit *sample redetection* `count(t+1,j)>0`. Only predictors observed at t or earlier are legal. All 14 entire independent metapopulations are held out one by one. Because the experiment was sampled before scheduled movement, current same-time source states are observed before any subsequent relocation, but the precise realized organism routes are NOT measured in these files.

The declared reference contains current zero spell length, day, metapop-wide other-patch positive count, sum of counts elsewhere (proxy for prevalence/background abundance), nearest ring distance to an observed positive patch, own current sample volume, assigned dispersal kernel, and time block. The candidate adds only **number of detected sources exactly 1 and 2 ring steps away**—the positional configuration left unexplained by total source count and nearest distance. Model: fixed sklearn L2 logistic C=1, feature scaling fit only in training metapopulations, leave-one-metapopulation-out, equal-block mean log-loss C−R; 2000-seed descriptive cluster bootstrap is not confirmatory. This is a weaker reference than GEB's actual R3, not an estimate of true rescue.

**Mechanistic fork:** after controlling for overall observed potential donors and closest donor distance, extra near occupied patches could be a source-connectivity signal, but may also encode lagged shared environmental cycles, predator/prey phase, or sampling-probability variation. A negative C−R would demonstrate only predictive utility for a **sample-observation endpoint** in a published system. It does not identify transport, 0→1 genuine immigration, 1→0 extinction, fitness, or a causal spatial configuration effect. Positive C−R is simply heldout non-support. No posthoc subgroup direction can rescue the primary. Prey counts are intentionally excluded until source-original assay scaling is independently validated.
