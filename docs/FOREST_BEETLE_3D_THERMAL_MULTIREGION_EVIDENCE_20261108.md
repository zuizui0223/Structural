# 林冠甲虫・温度逃避・13景観の水平マクロ解析：原データゲート結果（2026-11-08）

## 一言の現在地

**林冠での甲虫捕獲増加はタイ2森林の地点対応で実証済み。しかし温度逃避を示す直接データは未取得。** 水平景観の別データでは、8か国13景観×207採集セルと森林量・都市化の原表を完全に結合できた。外来甲虫検出割合の都市化関連を事前に固定した探索検定では、**13景観間の一貫した増加を確認できなかった**。

### A. タイの三次元森林（独立森林n=2）

- 元 Punthuwat et al. 2024, DOI 10.1002/inc3.76 の Coleoptera 元GBIF SHA256 `1565cf6d7f1e7289e28756367e3d137f64723dc1fa0a06d799f6abdb523e1339`。
- 18対応地点×2季節、SLAM 144 Event、1,622個体。林冠899 vs 林床723、平均地点×採集期差+4.89（森林内サイト単位の符号反転p=0.00439、CI +2.31〜+7.61）。元原著は垂直/季節多様性を既に解析しているので独立的新発見ではなく、原本再解析・方法診断。
- 林冠は11.3〜26.4m、下層2m。サイト季節ごとに高度変化、固定高度モデルをSCIENCE STOP。期別高度と林冠/林床捕獲比の関連：1.12倍／高度10m、景観/季節調整置換p=0.5755、CIがゼロを横断。温暖化による上下逃避はこの解析では未検証。
- 水平β−距離の単調補間は0/4森林×期で条件を満たさず、「垂直何m＝水平X m」とは換算できない。既存の科レベル垂直Bray–Curtis 0.54778、水平方向0.51419の記述差を保持。
- 公開版の `scientificName` 1,073出現行のうち、属・亜科・科・目レベル1025行・1537個体。種の二名法48行・85個体、固有のモルフォ種コードが残るもの0。437モルフォ種（元論文）の同定行列は公開GBIFから復元不能。Source audit CI [#42443376402](https://github.com/zuizui0223/Structural/actions/runs/42443376402)成功。
- 元論文で HOBO 毎時の林冠/林床気温・照度を測定。しかしGBIF Event coreに原HOBO時系列なし。元論文の公開データ説明は昆虫3群のGBIF DOIに限る。温度×種固有の垂直移動を自分の新実測結果と呼ばない。

### B. 他の独立ソースのアクセス判定

- ベルギーMeerdaal森 Verdonck et al. 2025、Dryad DOI 10.5061/dryad.tmpg4f5b0：原著は**36区画・林冠被度・日別林床Tmicro・MacroT・土壌水分・地表オサムシとワラジムシ**、同じPlotIDで連結可能と記載。原Dryad file_stream URIで GitHub Actions HTTP403（[#42443612583](https://github.com/zuizui0223/Structural/actions/runs/42443612583)）、API v2ファイルでHTTP401（[#42443683907](https://github.com/zuizui0223/Structural/actions/runs/42443683907)）。原データの取得は**アクセス停止**であって、生物学的な非支持ではない。2経路失敗後、同じ修正の繰り返しはしない。検証コード・合成単体テストは存在。
- スウェーデン樹洞甲虫 `Osmoderma eremita` DOI 10.5878/856g-v725：公表メタデータでは外気・樹洞内各9,766時点、個体・再捕獲データ。SNDの記載を元にした直接APIダウンロードはHTTP404（[#42443852389](https://github.com/zuizui0223/Structural/actions/runs/42443852389)）。未取得であり温度/移動効果未実証。これは**単一樹洞資源専門甲虫**の温度環境で、層別森林群集の独立再現ではない。

### C. Nardi et al. 2026：8か国・13景観、水平森林甲虫

原論文 DOI `10.1002/eap.70194`、Zenodo v3 DOI `10.5281/zenodo.17044394`。原4ファイルMD5一致で毎回検証済。これは林冠/林床の上下層調査ではなく、林分周辺の森林量・都市化と主に材食性/キクイムシ等の監視データ。

- **207 `SITE,CELL_ID`採集セル**は捕獲0/1広表とトラップ環境表で全件一致。長表3,215の正のセル×分類ラベル存在も広表0/1と完全一致（3,215一致、0不一致）。13 `SITE`は森林・土地被覆表 `plot_id`13行と完全対応。監査 [CI #42444566790](https://github.com/zuizui0223/Structural/actions/runs/42444566790)成功。
- 広表は301分類ラベル（種の同定・努力の完全標準化を別途確認要）。在来Native 2,915出現セル行、外来Exotic 300。Nativeとして現れる分類ラベル287、Exoticとして21、**7分類ラベルは地域間でNative/Exotic状態が異なる**（同一景観内の状態矛盾は0）。種のナティビティは景観に条件付ける。
- 63?ではなく、元Nの合計は**61,769**、論文の群別集計 **61,755**（差+14）。除外条件が未確定のため、元論文と個体数総量が完全再現したとは呼ばない。**主探索検定はNでなく実際に両表で整合した0/1出現セルを使用した**。
- 唯一の主探索コントラストは、景観ごとに都市化指標を中心化し、同じ景観の15〜16採集セルについて**外来の捕獲分類ラベル比率 E/(E+Native)**との関係を見る。事前の解析仕様 [FOREST_BEETLE_URBAN_NATIVE_EXOTIC_PRESPEC_20261108.md](https://github.com/zuizui0223/Structural/blob/analysis/forest-macro-plot-environment/docs/FOREST_BEETLE_URBAN_NATIVE_EXOTIC_PRESPEC_20261108.md)を結果取得前にコミットした。
- 実行 [CI #42444893080](https://github.com/zuizui0223/Structural/actions/runs/42444893080)成功、13/13景観適格。**景観ごとの外来比率傾きの等重み平均+0.0036306／景観内都市化SD、景観bootstrap95% CI −0.003734〜+0.011836、地点内都市化置換p=0.3723。符号は正6・負5・ゼロ2。事前支持条件不達**。
- これは「外来甲虫はどこでも都市化に伴い増える」という一般単純説には支持が得られないことを意味する。ただし0効果の同等性を証明したものではない。13景観・8か国の国別種プールや管理/導入歴を独立に分離できておらず、種の移動経路や森林断片の源配置・因果効果を示していない。
- 元論文の主題は監視法・景観文脈。新規生物学的独立実験ではなく、原版を使った探索的再評価である。

## 次の単一主目標

**国・森林タイプを越える標準化甲虫×森林構造×温度の観測支持を成立させること。** NEON公式公開系はその可能性がある。

- NEON 2026 release `DP1.10022.001`：地表性オサムシ等、47の地上観測サイトを含む、2013〜2023年のpitfallでの species/morphospecies 同定・捕獲Event×Trap×Plot×時期がある。2023年に10→6 plot/サイト等の努力変更があり、季節によりbout数も変わる。
- `DP1.10098.001`：同じネットワークの植生構造／樹高・林冠情報、公開2024時点で42サイト。
- `DP1.00002.001`：多高度の単点吸引温度計によるタワー内の気温垂直プロファイル。**これは林冠/林床の昆虫トラップではなく塔の温度構造**。直接の虫の上下移動は検証できない。
- まず**3原製品の同一RELEASEにおけるサイト×観測年月の支持交差**と、現地森林ハビタットの適格判定を、NEON公式APIの**メタデータ**だけで調べる。サイト数47／42を足したり、非森林も全て含んだ数字を森林マクロ実測Nとは呼ばない。次の段階でAPI token が実際に必要ならアクセスゲートを明示する。生物効果は原応答・調査努力・位置精度が確認できるまで推定しない。
