# GIFT global archipelago study — pre-response boundary

This directory is a **separate prospective macroecology study**. It does not
modify the frozen Structural manuscript or add a new Structural gate version.

Before any GIFT checklist species-composition response is opened, the study
freezes:

- GIFT version 3.2;
- native Angiosperm checklist metadata filters;
- geometry-only exclusion of the closed A-Islands system;
- full non-null GIFT `arch_lvl_1/2/3` path as the archipelago identity;
- a minimum of 16 predictor-complete islands per archipelago;
- GIFT `dist` as the response-independent isolation metric;
- the global upper 25% of the final eligible-island isolation distribution as
  the primary extreme-isolation state; 70% and 80% cutoffs are non-rescuing
  sensitivities;
- response access at the **archipelago/list_ID surface**, because GIFT checklist
  requests expose the complete requested list and cannot server-filter response
  rows by `work_ID`;
- three burned-pilot archipelagos spanning extreme-only, paired-regime, and
  non-extreme-only q75 support;
- balanced response-independent spatial blocks formed by the farthest-island
  geodesic axis and four contiguous equal-count bins;
- 25/50/125/250 km graph radii inherited from the frozen A-Islands strong
  reference;
- the R0/R1/R2/R3/C reference ladder, fixed ridge model, and 5/5 class gates;
- H1, H2, H3 and the M4 claim ceiling.

The burned pilot may expose only the frozen pilot archipelago list surfaces. It
fits zero models and may emit no effect size or prediction score. Confirmatory
archipelago lists remain sealed unless the frozen estimability gate passes.

Any pilot failure consumes this protocol. It must not be rescued by changing
the q75 threshold, graph radii, reference, class gates, archipelago size floor,
or evidence partition after response access.
