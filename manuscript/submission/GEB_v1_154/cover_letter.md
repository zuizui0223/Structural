# Cover letter — Global Ecology and Biogeography v1.154

Dear Editors of *Global Ecology and Biogeography*,

Please consider our Research Article, **“When do source islands matter? Occupancy state changes topology-specific isolation across islands.”**

*Why this paper should interest GEB readers (under 250 words).* Island biogeography has long treated isolation as a central control on colonization and extinction, and metapopulation theory already recognizes that effective connectivity can depend on which source populations are occupied. We ask a narrower broad-scale question: **when does the exact arrangement of occupied conspecific source islands add information beyond source number, source proximity and generic island geography?** Across a fixed geography of 5,401 islands, a preregistered layer of 529 mammal species occupying only 1–4 pilot islands showed a strong held-out presence benefit from graph-path source information (C−R3 = −0.596; 95% interval −0.744 to −0.464), and the observed adjacency outperformed all 20 degree- and edge-length-matched null topologies. An adjacent preregistered 5–12-presence layer showed no topology specificity, while a higher-occupancy exploratory layer was likewise not specific to observed adjacency. The general result is therefore an **occupancy-regime change in topology specificity**, not a universal connectivity effect or monotonic rarity gradient. This addresses a core biogeographic issue: when physical geography is sufficient to describe isolation, and when the focal species' remaining source configuration adds information that geography alone does not.

We also test the stronger conservation inference rather than assuming it. In an independent three-wave Azores arthropod system, source-loss exposure was frozen before later outcomes were opened. Lost-source leverage did **not** improve held-out prediction of subsequent contraction (C−R2 = +0.000674; 95% interval −0.02130 to +0.02558). We retain this negative result as a biological boundary between topology-specific occurrence information and temporal demographic consequence.

The manuscript explicitly does not interpret graph edges as realized dispersal routes, does not infer rescue from static occurrence, and does not present source leverage as a validated management-priority score. “Ultrarare” refers only to occupancy in the frozen pilot island set.
