# GEB policy snapshot — checked October 2026

This file records the submission requirements used to build `GEB_v1_90`. It is a formatting/policy snapshot, not scientific evidence.

- Journal: *Global Ecology and Biogeography*.
- Submission: Wiley Authors / Research Exchange.
- Review: double anonymous.
- Scope: broad-scale general patterns and processes in ecology/biogeography; macroecological, comparative, spatial and modelling approaches are explicitly in scope.
- Research Article: typically about 5,000 main-text words, about 50 references, and 6–8 display pieces, with flexibility among these.
- Abstract: structured, no more than 300 words, headings **Aim, Location, Time period, Major taxa studied, Methods, Results, Main conclusions**.
- Running title: <40 characters.
- Title page: identifying author/affiliation information; only one corresponding author.
- Blinded manuscript: title, running title, abstract/keywords, main text, references, Data and Code Availability, tables/figure legends/figures as applicable.
- Data/code: analysis scripts/software should be archived in a stable repository. The journal states that GitHub by itself does not satisfy the stability requirement.
- Double-anonymous data/code statement: links must not compromise author anonymity; an anonymized stable review archive should be inserted before submission.
- AI-assisted tools: Wiley requires disclosure when AI technology contributed to manuscript development beyond basic spelling/grammar editing; authors remain responsible for all content and verification.

Re-check the live author guidelines immediately before the actual upload, because publisher policies can change.
