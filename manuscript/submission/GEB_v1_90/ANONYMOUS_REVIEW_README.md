# Anonymous review reproducibility bundle

This bundle accompanies a blinded manuscript on species-conditioned source-network information in island biogeography.

## Contents

- blinded manuscript and figure captions;
- frozen analysis contracts and result provenance needed to audit the primary claim boundary;
- analysis and diagnostic scripts;
- frozen prediction, held-out focal-response and diagnostic artifacts;
- submission-facing figures.

## What is not included

Raw biological response files are not redistributed here. The mammal occurrence source is publicly archived at Dryad (DOI: 10.5061/dryad.hmgqnk9j2), and response-independent island geography is archived at DOI: 10.21942/uva.22788464.v5.

## Reproducibility scope

The bundle is intended to let reviewers inspect the exact frozen prediction surfaces, held-out focal-response matrix, block scores, post-hoc diagnostics and figure-generation inputs used in the manuscript. It does not authorize reopening, refitting, or redefining the one-shot response-access workflows.

The global mammal result is explicitly nonconfirmatory exploratory evidence. The bundle preserves that status and the manuscript's claim boundaries.

## Anonymity

Author names, affiliations, acknowledgements, funding information and public development-repository URLs are intentionally excluded from this peer-review bundle. The archive should be uploaded to a stable private-for-peer-review repository before submission.
