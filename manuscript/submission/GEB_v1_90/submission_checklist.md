# GEB submission checklist v1.91

Source: current Global Ecology and Biogeography author guidelines checked October 2026.

## Scientific / format fit

- [x] Broad-scale macroecology / biogeography question.
- [x] Global-scale island dataset and general conceptual conclusion.
- [x] Research Article format.
- [x] Main manuscript is below the journal's approximate 5,000-word Research Article target.
- [x] Structured abstract is below 300 words.
- [x] Structured abstract contains: Aim; Location; Time period; Major taxa studied; Methods; Results; Main conclusions.
- [x] Running title is <40 characters.
- [x] Main text uses Introduction, Methods, Results, Discussion and Conclusions.
- [x] Data and Code Availability Statement included.
- [x] Figure legends prepared separately.
- [x] Evidence classes remain explicit and no fresh/cross-taxon confirmation is claimed.

## Double-anonymous review

- [x] Blinded main-text draft contains no author names or affiliations.
- [x] Public GitHub URL is omitted from the blinded manuscript.
- [x] Peer-review code/provenance is supplied as a neutralized Supporting Information ZIP rather than by linking the public development repository.
- [x] Neutralized SI workflow removes GitHub workflow IDs, commit SHAs, public-repository strings, comments/docstrings and versioned public filenames from review code snapshots.
- [x] Raw Dryad biological response bytes are not redistributed in the SI ZIP.
- [ ] Check final DOCX/PDF document properties for author identity before upload.
- [ ] Check final figure/SVG/PDF metadata for author identity before upload.
- [ ] Confirm acknowledgements appear only in the identifying title-page file.
- [ ] **Recommended for strongest anonymity:** temporarily make the public development repository private during peer review, because the repository currently contains manuscript/code history that could theoretically be found by deliberate searching. This requires repository-administration access and is not changed automatically by the analysis workflow.
