# GEB v1.217 — working-only cover letter

Dear Editors of *Global Ecology and Biogeography*,

**Working title:** Geographic source graphs predict mapped island mammal ranges without distinct source territories

The study compares a geographically constructed k-nearest-neighbour source graph with an already source-aware Euclidean reference and 20 degree-/edge-length-bin-matched rewired graphs. The strongest prediction result concerns 529 mammal species with 1–4 positive pilot island cells in a curated IUCN range-map-derived matrix: original C improved log loss of held-out positive labels and outperformed all 20 rewires. However, on average 90.18% of the original C−R3 improvement remained with the rewired graphs. A separate posthoc geometry-only analysis found that source influence fields co-covered rather than partitioned target islands; independent Azores temporal source-loss leverage was unsupported.

This is **within-map geographic prediction**, not measured dispersal or direct survey confirmation of extant populations. Current independent validation is insufficient for a stronger causal or conservation claim, so this letter is a working draft only and is NOT approved for journal submission.
