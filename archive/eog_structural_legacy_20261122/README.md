# Historical EOG Structural paper assets

These files are **unmodified historical source versions** that were not identical to the current Structural study tree when EOG's former stand-alone structural manuscript lane was retired.

The 70 matching canonical files remain in their normal paths. The remaining 19 historical files are archived below this directory at their original EOG paths. The source snapshot and all paths/Git blob SHA/byte sizes are recorded in [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json).

**Do not activate these archived tests or overwrite current Structural submission assets from them.** This is a provenance transfer, not a reopened analysis, positive endpoint or scientific revision.

Current Structural result/response data and mainline are unchanged.
